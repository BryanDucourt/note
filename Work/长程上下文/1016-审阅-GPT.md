## 一、事实错误与机制上的过度概括

### 1. MEM：“子任务失败时不更新记忆”被写成了统一规则

**Claude 的位置**：一页摘要；MEM §3“更新与一致性”“完成判定”；四篇对比表。

Claude 写“子任务没成功时记忆不更新”，并据此将记忆更新时机直接等同于完成判定。

**原文情况**：

- §III-B 把语言记忆定义为过去语义事件的摘要，由高层根据旧摘要、观测和任务决定何时、如何更新。
- 标签生成要求保留未来执行仍需要的信息，并允许删除或合并旧信息。
- p.6 用反复抓碗的例子解释：抓取尚未成功时，不必把每次重复指令都追加进去。
- p.3 还把“哪个子任务反复失败”列为长期记忆需要支持的信息。（M pp.3、6）

正文没有给出“所有失败都禁止更新”的硬门控规则。

**应改为**：

> 高层学习何时更新摘要；论文给出重复抓取失败时保持摘要、成功后再更新的例子，未说明统一的成功门控规则。

同一行的“没有回头修改已写入内容的机制”也需要改。方法明确允许重写、删除和压缩；**显式发现错误、撤销错误记录及修正其后续影响的流程，论文未说明。**

**【推断】影响**：MEM 确实维护任务进度，但“任何记忆写入都等于完成判断”会把一般语义摘要缩窄成成功事件日志，并进一步夸大它与我们双消费者错误问题的直接重合。

### 2. “四篇都只有一个决策消费者”与任务定义及 MEM 原文不符

**Claude 的位置**：一页摘要、§7“任务规模”；与 MEM §3 自己写的“两个消费者”也不一致。

任务说明明确把 VLA／技能执行器计入消费者。MEM 的公式区分：

- 高层：接收目标、观测和旧语言记忆，输出下一子任务及新语言记忆；
- 低层：接收目标、子任务及短期观测，输出动作。

低层条件式没有直接输入长期摘要 \(m_t\)。（M §III-A，p.3；图2）

因此应写：

> MEM 有高层规划与低层动作两个功能消费者；它没有单独设置并评估完成验证消费者。

是否共享参数是另一个问题，不能用参数同源来合并功能消费者。

Claude 在 novelty 中把 LatentMem 放进“为单个消费者按角色……定制压缩”，也容易产生同样误导。按本任务允许引用的上一轮笔记，LatentMem 服务多个角色；应改为“为不同角色分别生成记忆”。[1015-Claude 的消费者说明](/Volumes/2T/note/Work/长程上下文/1015-精读-Claude.md:55)

**【推断】影响**：“新增多个消费者”本身不足以形成我们的主要差异。需要落到哪些判断共享哪些事实、如何分别保留其证据，以及怎样评价联合错误。

### 3. MEM 图6不支持“单一记忆都不超过无记忆”

**Claude 的位置**：一页摘要；MEM §5“两种记忆缺一不可”。

重新查看原图后：

- **Recipe Set Up**：仅视频和仅文本两组均低于无记忆；
- **Clean Kitchen**：仅视频和仅文本两组均高于无记忆；
- 完整 MEM 在两项任务中都明显高于单一组件。（M 图6，p.6）

Claude 对备料任务的观察正确，但把它推广成全部任务上的结论有误。

**【推断】我支持的表述是**：

> 两种记忆的组合在所测长程任务中效果最好；单一组件的收益具有任务差异。

“两种记忆缺一不可”比图6能支持的范围更强。这里保留图中的大小关系即可，无需估读未标注的百分比。

## 二、推断分歧：我更支持哪一边

### 1. MEM 的结构值得研究，但“写错就共同出错”尚未成立

**Claude 的判断**：MEM 已把写记忆和判定完成合在一起；记忆一旦写错，规划和完成判断会同时继承错误。

**我的判断**：存在合理的共同错误风险，但需要区分错误产生和传播的路径。

原文的高层联合输出为：

\[
\pi_{\mathrm{HL}}(l_{t+1},m_{t+1}\mid o_t,m_t,g)
\]

新子任务和新摘要共同生成。（M §III-A，p.3）

**【推断】至少有三种不同情况**：

1. 当前观测理解错，导致下一子任务和新摘要同时出错；
2. 旧摘要已经错误，后续高层采纳它并作出错误决策；
3. 摘要存在错误，但当前观测或其他信息使后续决策得到纠正。

第一种主要涉及共同上游错误，第二种才直接涉及历史表示的错误传播。论文没有分别测量这些路径，也没有独立的完成判定输出供配对评分。

**【推断】我更支持我稿中的条件性表述**：把 MEM 视为研究递归摘要及进度错误的具体系统依据；将共同错误频率与传播后果作为待研究问题。Claude 的风险假设值得保留，但其 novelty 段把假设提前写成了既定事实。

“当前最强的系统”也应收窄为“已在真实机器人长程任务中展示明显收益的系统”；本轮材料没有提供跨系统排名依据。

### 2. MeMento 的样本量不能从百分比反推出36个

**Claude 的判断**：52.78% 对应19/36，其他比例像1/18的倍数，因此可能只有36个实例；与摘要基线只差两三个实例；15.67%可能是笔误。

**原文情况**：固定版本没有交代这些实验的实例数、重复次数及完整统计口径；图表又混用不同精度的百分比。（E 表2、§5.6、§6.1，pp.5、8–9）

**【推断】我更支持“样本量未知”，不支持继续使用36作为评判前提。** 四舍五入、更多样本、跨设置平均等情况都可能产生相同百分比。对15.67%的“笔误”怀疑又依赖这个未经确认的分母。

应删除摘要中的“评测规模很小”和导师问题中的“只有约36个实例”，改为：

> 样本量与不确定性未报告，无法判断增益的统计稳定性。

对证据质量的担忧可以保留，依据应使用已发现的报告缺口和内部数值问题，见第三节。

### 3. MeMento 的“双目标覆盖”和“自然错误率”，应分别判断

**双目标压缩：我更支持我稿的“部分覆盖”。**

MeMento 分别评估决策准确率和历史事实 QA；QA 包含 yes／no／unknown，并报告 macro-F1。（E §6.2、图5，p.9）

**【推断】这已经提供了共享记忆服务两类能力的直接基础。** 它尚未研究物理任务完成判定，也没有把同一事实上的行动选择和完成确认配对。Claude 用“只有一个决策消费者”直接判为未覆盖，会低估这一近邻。

我们的增量应进一步说明：物理完成确认需要哪些状态变化、实例身份和时序证据，以及这些证据与行动选择需要的信息怎样相互影响。

**自然表示错误率：我更支持 Claude 的“未覆盖”，并收窄我稿的判断。**

MeMento 的迷失／重复探索分类统计的是 agent 失败，事实 QA 测量的是记忆支持回答的能力；它没有直接统计自然轨迹中表示写错、下游采纳及执行损失的比例。（E §4.2.2、§6.2）

**【推断】我稿将这项写为“部分覆盖”容易混淆统计对象。** 更准确的写法是“已有相关诊断，但自然表示错误率及采纳链条未测量”。LTE 的失败分类也应保持其“失败样本内原因构成”的分母。

### 4. COMPACT-VA 的误差条冲突值得重视，“差距接近噪声”缺少统计依据

**Claude 的判断**：表I为68.3% ±0.2%，表IV为68.3% ±2.1%；按后者看，与65.6%的差距接近噪声，因此规划对齐的证据弱。

这两处冲突确实存在；正文没有解释主结果的“±”代表什么，四个随机种子的明确说明出现在码本统计部分。（C 表I、IV；§V-D，pp.6–7）

**【推断】我更支持我稿的限定判断**：

> 报告的数据支持在相同历史及观测 token 预算下，规划对齐变体取得更高的离线行为分数；增益的不确定性与重复稳定性待澄清。

直接采用较大的“±”判定差距接近噪声，需要误差条定义、重复次数及比较方式。现有材料不足以完成这一步。

同样，“一般驾驶能力持平”宜理解为表II中的描述性结果。若要主张严格的无退化或安全非劣性，还缺对应统计设计。

### 5. MeMento 的条件消融，需要把具体模块与广义主张分开

Claude 正确注意到：\(P\) 变体去掉关键词生成后，仍然编码原始要求。这一点很重要。（E §6.1，pp.8–9）

**【推断】我支持的结论是**：

- 原文支持“关键词化的偏好表示优于该实验中的直接要求编码”；
- “有偏好条件优于无偏好条件”没有被这项消融直接检验；
- “该变体可能整体训练失败”可以作为待查假设，但没有训练过程证据支撑。

因此，Claude 在“已证明以判定标准为条件压缩优于通用摘要”上的表述过强；我稿把关键词模块的报告结果判为支持更合适，但也应限定在该实验配置内。

### 6. LTE 的在线效率和时间标签，应按各自主张评价

**Claude 的判断**：

- 因离线建库很慢，“查询高效”证据弱；
- 因缺少准确率评估，“置信标签能提示过时”证据无。

原文同时报告了在线与离线成本：24小时视频在线查询0.43秒，顺序建库68.4小时，并行管线约42小时；附录还给出相对强 VLM 基线约1,545次查询的成本摊销点。（T 附录C、表8，pp.15–16）

**【推断】我更支持分开评价**：

| 主张 | 我的判断 |
|---|---|
| 建库后在线查询快 | **支持**，有直接时延测量。 |
| 少量查询或实时新建记忆时，总成本更低 | **证据弱／依部署条件而定**，离线成本很高。 |
| 时间标签区分窗口内观察与窗口前最后观察 | **有明确方法定义**。（T 附录F，p.18） |
| 标签准确识别错误、可靠校准当前事实可信度 | **未验证**。 |

**【推断】HIGH 仍可能对应错误身份或错误描述；标签主要表达观察与查询的时间关系。** 将它直接当成通用可靠性分数，会掩盖我们真正需要处理的表示错误。

### 7. 用仿真真值构造 LTE 主基线的建议，应拒绝

**Claude 的位置**：LTE §7“如果当基线”。

它建议用“仿真真值或我们的四类记忆替代感知管线”。

[1015讨论结论](/Volumes/2T/note/Work/长程上下文/1015-讨论-结论.md)已明确约定：

- 仿真真值留在评分端；
- 实例映射、转化事件和未来帧等不进入模型；
- 各组拥有相同的合法历史、当前观察和原始记录访问权；
- 现有四类记忆由人工整理，不能用于估计目标模型的自然表示错误率。

**【推断】我支持我稿的接法**：用统一的、来自合法观测的感知或记录输出，分别构造 LTE 式检索、简单状态表加检索和判定补证组。理想感知上界可以另行定义，但需要与主比较分开。

这会直接影响结果归因：若某组得到准确的对象身份和状态转化，收益可能来自额外信息，压缩与取证机制的贡献就难以判断。

## 三、遗漏

### 1. Claude 漏掉、且影响论文判断的内容

#### 1.1 MEM 图8比较时移除了长期语言记忆

作者为比较短期观察记忆的不同实现，在图8对应实验中明确使用**不带语言长期记忆的模型**，并在相同 π0.6 底座上重实现 Pool Memory 和 Proprio Memory。（M §IV-C，p.7）

## 五、判断尺度与 novelty 论证

### 1. 我支持“仍有研究空间”，但当前论证需要重写两项依据

**【推断】在本轮四篇及1015笔记覆盖的工作中，没有发现足以直接覆盖我们完整问题的工作。** Claude 保留方向的结论站得住。最有价值的部分是：

- 对同一事实或目标进行规划与完成判定的配对评价；
- 在自然轨迹中分开统计表示错误、错误采纳和执行损失；
- 比较按需补证、共享摘要重生成及状态表检索的收益与成本。

但以下两项论证不成立。

**第一，“从任务级固定条件推进到每步变化条件”并非共同的文献分界。**

- MeMento 的偏好在任务内固定，这个对比成立；
- COMPACT-VA 的 prior 根据当前压缩历史预测意图，意图随历史变化；
- LTE 根据当前查询解析约束并检索；
- 上一轮 REFLECT 已按子目标回查事件证据，RCR也包含阶段相关路由。（C §III-C；T §3.5；1015两份精读的对应部分）

**【推断】更有意义的差异是完成判定所需的证据内容及其联合关系**：对象是不是同一个、状态何时改变、操作顺序是否满足要求、哪些观察已经过时。仅把条件改成随步骤变化，novelty 支撑较弱。

**第二，同预算三方对照无法自动分离三种作用。**

Claude 说它可以把收益分别归到证据路径、问题来源和模型配置上。但三个方法如果同时改变取证方式、问题提示和模型配置，结果仍然混杂。

**【推断】三方对照回答方法是否有收益；因素归因还需要固定或交叉改变这些因素。** 1015结论已经分别安排正确完成条件、错误子目标实验及模型交叉，应在 novelty 段保留这些区分。

### 2. “已有先例，所以机制只能当变量”过度收缩了贡献空间

**Claude 的位置**：§6、§7、§8。

它多次写：

- 机制本身不当贡献；
- 按消费者定制已是常规设计；
- 条件压缩、统一存储和多视图只能作为设计选择。

**【推断】我不同意这种一概排除。** 原样使用已有模块时，确实应说明继承关系；但对这些机制作有意义的改进，仍然可以形成贡献。例如：

- 在已有对象、时间和视觉锚点基础上，表达完成条件需要的状态转化及跨步骤关系；
- 识别共享摘要对某次判定缺少哪类证据，再决定保留、补取或重新压缩；
- 在同一预算内兼顾行动选择与完成确认，形成更好的信息分配机制；
- 当对象身份或描述已经错误时，通过可追溯证据恢复判断依据。

这些方向都需要具体方法和结果支持，也都有清楚的已有基础。

**【推断】1015中“角色定制不作为主线”的决定可以继续遵守；它没有要求永远放弃机制贡献。** 更合适的尺度是：不把组件名称本身当作新增贡献，认真判断我们推进了它的哪一步。

### 3. 对“共同错误”主线，应保留检验，也保留方向发展的余地

Claude 提醒自然共同错误可能很少，这个风险合理，与1015先估发生率的决定一致。

**【推断】我支持先检验自然发生率，但不预设整个双目标压缩方向随之失去价值。** 如果共同错误确实少，可以收缩共同错误传播这条解释，继续判断是否存在“行动仍正确、完成确认已经缺少证据”的系统性差异，以及按需补证是否有成本收益。

反过来，如果共享摘要重生成或简单状态表检索在相同条件下已经达到同等效果，方法贡献就需要进一步收窄。这是比较结果决定的边界。

### 4. 建议替换的 novelty 论证

> **【推断】我们拟研究长程具身任务中，历史压缩如何同时保住行动选择与完成确认所需的证据。** MEM提供了进度摘要与动作策略的结合，MeMento和COMPACT-VA展示了需求与规划对齐压缩，LTE及上一轮工作提供了对象级锚点、角色定制和事件回查的基础。我们进一步以同一事实、目标和时刻上的成对判断为研究单位，分析身份、状态和时序信息的压缩损失，何时被规划与验证共同采纳，以及何时仅破坏其中一种能力；据此设计针对证据缺口的保存或补取机制，在相同合法历史与总预算下，与共享摘要重生成、状态表加检索比较。新增贡献可以来自联合证据需求的建模、自然错误采纳链条的测量，以及据此改进的证据预算分配；通过控制证据路径、问题来源和模型配置，确定收益来自哪里。共同错误是否常见、补证是否值得，由实验回答。

**【推断】这段论证比“首次把固定条件变成动态完成条件”更稳固，也给实质性方法改进留下了空间。** 当前还需要完成具体机制和实验，不能将计划中的贡献写成已经取得的结果。
