需要什么样的上下文、如何检索、如何排列

|环节|要回答的问题|
|---|---|
|**检索**|从历史中找到哪些候选证据？|
|**重排与选择**|哪些候选更值得进入有限上下文，哪些需要联合保留？|
|**上下文排列**|对已经选定的同一批证据，按什么顺序和结构提供给规划器？|


- 什么样的历史信息才能构成支持当前决策的充分条件
- 给定历史观测、后续行动和环境变化，一条历史证据在当前还能支持什么状态判断？这种支持程度何时足以支撑行动？

本周计划
上下文结构设计：给出一种上下文结构设计，在behavior上实验，判断提供的上下文对规划的影响，比较成功. 响应时间
	明确信息组成；构造几种上下文；在同一批决策节点上比较；区分缺信息、状态过时与排列影响
	
| 信息部分        | 本周需要明确的问题               |
| ----------- | ----------------------- |
| 任务与当前子目标    | 当前到底需要判断什么？允许哪些动作？      |
| 当前观测        | 机器人现在实际知道什么，而不是仿真器知道什么？ |
| 对象状态与任务进度   | 哪个对象完成了什么？哪些步骤还没有完成？    |
| 历史动作及结果     | 哪些只是发出了指令，哪些有成功或失败反馈？   |
| 支持证据与时间关系   | 当前判断依据哪次观测？之后是否出现修订或冲突？ |
| **尚未确认的信息** | 哪些动作前提仍然缺少证据，不能直接视为事实？  |

	核查环境与可用动作接口；选一个任务；接通观测、规划、执行与结果回传；保存可回放记录
