## 讨论用的一页摘要

**【推断】建议保留并推进我们的方向，把核心贡献放在“历史压缩怎样同时保住行动选择与完成判定，以及如何按需恢复两者缺失的证据”。** 四篇已经提供了任务条件压缩、进度记忆、规划监督和多视图检索的直接基础。我们可以在这些基础上研究同一条事实对两种判断的不同要求，以及共享表示失真后的共同错误；已有相似机制为这条路线提供了起点。（MEM §III–IV；MeMento §5–6；COMPACT-VA §III、V；LTE §3、附录 E–G）

### MEM: Multi-Scale Embodied Memory for Vision Language Action Models

#### 1. 基本信息

Marcel Torne、Karl Pertsch 等；主要团队为 Physical Intelligence，署名包含 Stanford、UC Berkeley、MIT。固定版本为 `2603.03596v2`，2026-03-08。当前 [arXiv 条目](https://arxiv.org/abs/2603.03596)提供论文与项目页，未标注正式会议或期刊出处；其他发表情况未核实。（M p.1）

原作者公开实现未找到；[作者项目页](https://www.pi.website/research/memory)提供论文、方法介绍和机器人演示，未给出 MEM 实现链接。

#### 2. 一句话和要解决的问题

**把机器人历史分成适合高层规划的长期语言摘要和适合低层控制的短期视频记忆，再联合训练具有这两种记忆能力的策略。** 作者针对的是：长时间保留密集观测成本过高，而单一模态的压缩容易丢掉语义进度或精细操作信息。（M §I、III）

【推断】最扎实的贡献是两种时间尺度、两种模态与分层策略的配合，以及相应的真实机器人消融。它也提供了一个直接适合我们继续研究的系统：高层生成的历史陈述会成为下一轮规划的依据。

#### 3. 方法

| 维度 | 具体机制与出处 |
|---|---|
| **历史规模** | 长程任务最长约15分钟。预训练输入6次观测，间隔1秒；后训练扩展至作者所报18帧、54秒的观测记忆。语言摘要 token 上限和整体压缩率论文未说明。（§III-D、IV-A，p.5） |
| **存储来源** | 在线保存当前 episode 的近期观测与语义事件摘要。跨任务数据用于预训练、后训练，不是推理时检索过去任务经验的数据库。（§III-B/D；§V） |
| **表示形式** | 长期为自然语言 \(m_t\)；短期为视频编码器输出及本体状态 token。视频在 ViT 内融合历史，最后只向 VLA 主干传当前时刻的视觉表示；每个历史本体状态经线性投影形成一个 token。（§III-C/D，pp.4–5） |
| **消费者** | 两个策略层：高层接收目标、观测、旧摘要，预测下一子任务和新摘要；低层接收目标、子任务、短期观测，生成连续动作。§III-A 的低层条件式未直接包含长期摘要 \(m_t\)。（§III-A，p.3；图2） |
| **压缩条件** | 语言摘要以任务目标、观测和旧摘要为条件；标签生成要求保留后续执行相关信息，并合并或删除内容。视频压缩通过动作学习获得任务相关性，没有显式的“本次完成判定问题”输入。（§III-B–D） |
| **训练信号** | 用子任务语言标注及成功/失败标志，让现成 LLM 生成摘要标签。策略结合离散 FAST 动作预测与 flow-matching 动作专家训练；专家梯度不回传 VLM，VLM仍通过其训练目标学习。离线成功标志不是在线输入式中的字段。（§III-B/D，pp.3、5） |
| **更新与一致性** | 高层递归生成 \(m_{t+1}\)，可保留原摘要、追加或压缩。正文举例：反复抓取失败时不把每次指令都加入摘要，成功后再更新。证据来源、过时标记、摘要纠错及派生信息失效规则论文未说明。（§III-B、IV-A，pp.3、6） |
| **完成判定** | 摘要记录已完成事件；策略据此继续或结束行为。拆购物袋任务把“全部取出并回到 home 表示结束”纳入成功条件。没有独立完成验证器，也没有独立于规划输出的完成证据接口。（附录 B.3，p.14） |
| **共享 vs 分开** | 有语言/视频消融及朴素子任务历史拼接对照。没有同预算的共享摘要与消费者专用视图比较，也没有状态表加检索。（图6，p.6） |
| **错误分析** | 描述重复失败造成的训练—推理分布变化，以及有记忆策略如何修正抓取和开门方式。未统计摘要写错率、错误采纳率或规划—验证共同错误。（§IV-A/B） |
| **成本** | 视频编码后进入主干的视觉 token 数与单时刻输入相同，但编码器仍处理历史。图3在单 H100、四路相机下比较推理时间，标出300毫秒参考线；完整高层摘要调用、总 token、存储和整任务时延论文未说明。（§III-C/D，图3） |

短期编码的具体做法是：每隔四层在空间注意力之外增加因果时间注意力，在相同 patch 位置之间融合历史；作者给出的复杂度从联合时空注意力的 \(O(n^2K^2)\) 改为 \(O(Kn^2+nK^2)\)，随后丢弃过去时刻的输出 token。新增时间位置编码是固定的，编码器没有因此增加可学习参数。（M §III-C，pp.4–5；附录 C，p.15）

一个复现细节待核实：§III-A 把高层观测写成 \(o_t\)，§III-B 又写成 \(o_{t-K:t}\)，没有进一步明确实际高层窗口配置。（M p.3）

### MeMento: Long-Horizon Embodied Decision-Making via Multimodal Memory Compression

#### 1. 基本信息

Bingxuan Li 等，UIUC 与 Northwestern University。固定版本为 `2608.01456v1`，2026-08-02，PDF 标注 Preprint，全文10页。[当前 arXiv 条目](https://arxiv.org/abs/2608.01456)仍提供这一版本，未列正式发表信息。未找到可核验的作者代码或数据发布入口。（E p.1；arXiv 条目）

#### 2. 一句话和要解决的问题

**根据用户选房偏好，把跨住宅探索获得的图像与文字历史压成连续记忆 token，帮助冻结 VLM 继续探索、比较候选并作出最终选择。** 作者把主要困难拆成隐含偏好推断与长历史证据整合，并提出 DunphyBench。（E §1–3、5）

【推断】它和我们的联系很直接：压缩受决策需求控制，压缩后的记忆又接受事实问答检查。可以从这里继续研究“支持当前选择的表示，是否也保留了核实该选择所需的全部依据”。

#### 3. 方法

| 维度 | 具体机制与出处 |
|---|---|
| **历史规模** | 表1给最大允许 **1,500步**。默认 **7项偏好**，每个难度层 **19个干扰住宅**；候选池公式为 \(1+3M\)。最近历史基线保留20步。输入原始历史总 token、实际训练轨迹长度分布论文未说明。（§2、4.1、5.6.1） |
| **存储来源** | 当前实例在多个候选住宅中的探索历史；每步包含 ego-view、map-view、观察文本和动作文本，附时间与环境身份。（§5.1，pp.6–7） |

### COMPACT-VA: Planning-aligned Token Compression for Long-Context Autonomous Driving

#### 1. 基本信息

Zhixuan Liang 等，主要为 NVIDIA、香港大学，另有 Stanford 和 Georgia Tech。固定版本为 `2606.07464v3`，2026-08-19。PDF首页写明 **2026-08-09录用**，页眉标注 IEEE RA-L；[arXiv 条目](https://arxiv.org/abs/2606.07464)也标注 RA-L 2026 accepted。未找到作者公开实现。（C p.1）

#### 2. 一句话和要解决的问题

**把多相机驾驶历史压入分层 token 缓冲区，再通过未来轨迹监督的意图 latent 与轨迹损失，使压缩保留对停车、让行和通行决策有用的信息。** 目标是处理驾驶中的秒级历史依赖，并满足推理预算。（C §I、III–IV）

【推断】最值得借用的贡献是把压缩目标与行为正确性连接起来，并设置同观测 token 预算的消融。它为我们研究完成判定提供了方法论基础：压缩质量应由具体下游判断来评价。

#### 3. 方法

| 维度 | 具体机制与出处 |
|---|---|
| **历史规模** | 主设置为 **5秒、4Hz、20个时刻、2路相机，共40张图**；每图160个视觉token，未压缩共 **6,400**，压缩后 **1,424**，作者记为 **4.5×**。（§V-A，p.5） |
| **存储来源** | 当前驾驶过程的多视角历史观测与 ego 历史轨迹；训练集驾驶轨迹提供监督，没有跨任务经验检索。（§III-A–C） |
| **表示形式** | 视觉token经过Q-former，形成三级FIFO记忆；另有历史轨迹token和预测意图token，交给统一VA策略主干生成未来轨迹。（图2；§III） |
| **消费者** | 一个统一驾驶策略；prior/posterior是训练及表示模块，不是规划、监控、任务评估等独立消费者。主干不使用文本指令。（§III-A/C） |
| **压缩条件** | Q-former显式结合时间、相机及ego历史轨迹。作者另提出意图条件化与规划联合训练。图2画出 \(t-1\) 记忆到prior及意图反馈，正文推理段按压缩→prior→策略描述，具体更新调度未完整展开。（图2；§III-B/C） |
| **训练信号** | \(L_{\text{traj}}+\lambda_{\mathrm{KL}}D_{\mathrm{KL}}(q\|p)+\lambda_{\mathrm{commit}}L_{\mathrm{commit}}\)。posterior训练时看未来轨迹，prior只看压缩观测；策略训练与推理都使用prior latent。Q-former、编码器、码本和策略主干联合优化；视觉前端冻结状态未说明。（§III-C，p.4） |
| **更新与一致性** | 近期、中期、远期三级FIFO，累积压缩比分别为 **1、16、80**；主设置每级覆盖 **4、5、11个时刻**。没有事实版本、过时结论或证据失效管理。（§III-B、V-A） |
| **完成判定** | Stop SR与Go SR评估同一策略的驾驶行为；没有独立的任务完成判定器。指标由预测轨迹与真值行为条件计算。（§IV-B） |
| **共享 vs 分开** | 有相同5秒、40图、1,424观测token的“无规划对齐”基线；没有通用语言摘要、状态表加检索或多消费者共享/分开比较。（表I、IV） |
| **错误分析** | 报告roll-through等行为错误；对intent token做mean、shuffle、randomize、remove干预。干预对象是策略latent，没有测表示事实错误或多消费者共同错误。（表I、VII） |
| **成本** | A100上20次计时：长历史无压缩 **1,253.52ms / 10.51GB**；方法 **377.08ms / 3.95GB**。1,424是观测token数，另有轨迹、意图等输入；各处理阶段的计时边界及持久存储未分列。（§V-C、表III） |

层级结构仍采用时间衰减偏置：近期保留完整分辨率，远期使用更强压缩；学习的是各层保留哪些特征。论文详细的离散方案使用32维 latent、20项码本，后验把64个未来waypoint转成128个控制token，再聚合为5个token。（C §III-B/C、V-A）

【推断】使用未来轨迹作为训练监督在这里是清楚披露的设计。应追问的是：它教会压缩器保住了什么历史证据，以及新增latent和策略联合训练分别贡献多少。

1. 【推断】单靠行动或任务成功监督，是否已经会保留完成判定需要的信息？
2. 【推断】新增完成监督带来的收益，来自更好的压缩还是更强的下游判别器？
3. 【推断】我们能否提供与表I一样清楚的同历史、同预算对照？

### LTE: Linguistic Trajectory Encoding for Efficient Long-Horizon Spatial Memory in Embodied Agents

#### 1. 基本信息

Tianyidan Xie 等，南京大学、UBC、浙江科技大学、华为、天津大学。固定版本为 `2609.04802v3`，2026-09-29，22页。（T p.1）

**发表与代码信息需要更新：** [当前arXiv条目](https://arxiv.org/abs/2609.04802)和[作者项目页](https://sealical.github.io/st-mem/)标注 **NeurIPS 2026 accepted**；正式会议录用名单未独立核实。作者发布了 [ST-Mem核心代码与演示](https://github.com/Sealical/st-mem)，本次已静态抽查，固定commit见第6部分。

#### 2. 一句话和要解决的问题

**把对象运动历史表示为可用语言检索的阶段描述，并绑定稀疏三维位置与视觉证据，通过关联视图回答长时间范围内的状态、位置和身份查询。** 论文关心的是“某对象经历了什么、什么时候出现、最后在哪里”，实验主要为第一视角视频检索。（T §1、3）

【推断】它最有价值的推进是把对象身份、时间、语义和几何组织到同一条可查询记录里。它对我们既是重要先例，也是实现按判定取证的可借用基础。

#### 3. 方法

| 维度 | 具体机制与出处 |
|---|---|
| **历史规模** | Ego4D NLQ视频平均 **8.2分钟**；SMB的LOR回看窗口为 **2、6、12、24小时**。EgoLife来源为6人、7天、共300小时，单会话最长50小时；这些不是每个query都使用的历史量。（§4.1；附录 A） |
| **存储来源** | 当前持久环境的连续第一视角视频及音频，经检测、跟踪、几何重建、描述生成和转写加工。没有跨任务策略经验库。（§3.1–3.4） |
| **表示形式** | \(LTE(o_i)=(C,A_{\text{spatial}},A_{\text{visual}})\)：带时间区间的文字描述、稀疏3D锚点、对象裁剪与框。Object、Scene、Text、Event、Image五视图相互关联，另用octree作空间裁剪。（§3.3–3.4，p.5） |
| **消费者** | NLQ、VQ2D、STR、LOR四类检索管线；涉及文本、视觉与空间接口。没有接入规划器、VLA或执行监控。（§3.5；§5） |
| **压缩条件** | 建库依赖跟踪连续性、轨迹几何和运动阶段；检索时才按对象、时间、空间、语义约束路由。Douglas–Peucker容差 **0.15m**；缺测阈值 **2秒**；视觉锚点最大间隔 **10秒**。（§3.3；附录 B.3、G.2） |
| **训练信号** | 使用预训练SAM3、ViPE、Qwen3-VL、Qwen3、嵌入模型等，论文按zero-shot报告，没有针对压缩器或消费者的任务训练。人工标注用于SMB评测；是否有额外调参数据及其划分未说明。（§3.2、4.1；附录 B） |
| **更新与一致性** | 新对象可增量加入，复用既有3D坐标框架并更新关联视图。跟踪缺失时保留最后观察位置；自动修正ID错误明确列为未来方向。跨视图检查及错误撤销尚未实现为完整机制。（§3.4；附录 E、G.1） |
| **完成判定** | 返回对象、时间区间、位置和证据，未进行任务完成判断。HIGH/MEDIUM/LOW由观察时间和查询窗口关系决定；没有报告其概率校准或错误识别能力。（§3.5；附录 F） |
| **共享 vs 分开** | 有组件消融、保留单一通道消融、结构化记忆及VLM扫描基线。没有同总预算的消费者共享摘要/专用视图，也没有对统一感知记录上的简单状态表加检索作匹配比较。（表3、5、12） |
| **错误分析** | 随机分析 **100个失败案例：50个STR、50个LOR**。STR失败中跟踪占 **34%**、描述模糊占 **28%**；分母是已失败样本。没有规划—验证共同错误或后续执行损失。（附录 E，p.17） |
| **成本** | 24小时视频：稠密轨迹 **856MB**，LTE部分 **32.8MB**，系统总存储 **134MB**；查询 **0.43秒**。建库顺序执行 **68.4小时**，并行pipeline约 **42小时**；作者估算约 **1,545次查询**摊平相对VLM扫描的成本。（表4、8；附录 C） |

正文的“tracking-gap”划分依据是**是否持续被观察到**；可靠观察的其他区间作为motion intervals处理。缺测区间保留最后观察位置，视觉证据保留缺测前、重新观察后的可见边界。（T §3.3、附录 G.2）

【推断】这一区分很重要：运动描述和最后已知位置都带有明确的可见性边界；“有一个当前位置”不应自动被下游当作持续观察结果。时间标签仍需结合身份与描述本身是否正确来理解。

#### 4. 实验

Ego4D NLQ为 **5,462个query、303个验证视频**；VQ2D为 **4,500个query、1,200个验证clip**。SMB包含STR和LOR各 **300个query**，STR涉及 **232个对象实例**，其中 **113个query涉及两个对象**。没有报告重复运行方差或置信区间。（T §4.1；附录 A.3）

| SMB-STR | 完整系统 **45.3%**；Q3VL-235B+GD **31.9%**；VideoAgent **24.7%** | 表3 |

SMB上的KFMem由作者按3D-Mem式设计构建；VideoAgent使用公开实现并换成相同Qwen3-VL-8B；VLM基线由作者配合Grounding-DINO搭建。Ego4D表中其他既有方法数字是否全部重跑，论文未说明。（T §4.1；附录 G.4）

两个影响核心结论的边界：

- 标注时跳过SAM3跟踪失败的对象，比例为 **11.3%**；其中 **73%**为小于40×40像素的对象。（T 附录 A.3）【推断】这使基准对“能够可靠形成对象轨迹”的样本有所偏向，跟踪失败更严重的环境需要另测。
- **去掉LTE后，LOR仍为48.7%。**（T 表5）【推断】LOR优势应主要归于对象索引和空间检索系统；LTE新表示的直接收益最清楚地体现在STR，而不是四项任务都同等依赖它。

此外，正文称VLM基线采用2秒clip协议，附录G.4写3秒、3FPS、非重叠窗口；这一运行配置待澄清。（T §4.1；附录 G.4）

## 四、对我们问题的总体影响

### 1. 双目标压缩：已有基础很强，可以继续深化

MEM把完成进度写进规划记忆，MeMento同时评估决策与历史事实问答，LTE测量不同表示组件对多种查询的影响。（M §III-B；E §6.2；T 表5/12）

【推断】我们的增量应具体落在**同一任务事实上的两种判断需求**：哪些压缩对下一步行动没有明显影响，却让完成确认缺少对象身份、顺序或结果证据；怎样在预算内同时满足这些需求。这样既延续导师的多消费者方向，也提供更清楚的研究对象。

### 2. 错误连带：差异最清楚，但需要测出发生机制

本轮没有一篇报告同一历史事实出错后，规划器和完成判定器共同采纳错误的概率。LTE提供上游错误分类，MEM提供递归摘要结构，MeMento提供事实探针，COMPACT-VA提供表示干预实验。（各篇第7部分）

【推断】最有区分度的贡献是把这些部分连起来：**表示错在哪里、谁采纳了它、是否在同一目标上一起出错、补证后行动与判定如何变化。** 单看两个模块各自的准确率，会遗漏这个联合关系。

### 3. 按判定取证：重合最重，也最适合在已有方法上推进

MeMento已经按偏好压缩，COMPACT-VA已经对齐规划目标，LTE已经按查询路由并返回证据。（E §5；C §III；T §3.5）

【推断】值得继续推进的是**判定需要哪些联合证据，以及压缩后何时需要恢复证据**。例如，一次“物体已入碗”的记录是否还需要匹配其此前处理状态、实例身份和动作顺序。已有检索、锚点和压缩组件都能复用，贡献可以来自新的证据需求建模与预算分配，而无需重新发明全部系统。

### 4. 自然错误率：已有局部诊断，完整链条仍有价值

LTE的34%是50个STR失败样本中的跟踪失败占比；MeMento的21%和13%没有明确交代分母；COMPACT-VA和MEM主要报告末端行为表现。（T 附录E；E §4.2.2；C 表I；M §IV）

【推断】我们应在未经污染的轨迹中分别记录三个分母：被检查的表示事实、包含错误表示的下游判断、受影响的任务或续跑。注入实验用于解释条件性脆弱，自然发生率用于判断问题的重要程度；二者共同构成更完整的故事。

## 六、novelty 论证

【推断】**我们拟研究长程具身任务中面向行动选择与完成确认的联合历史压缩。** 在相同合法历史和总预算下，同一条事实的身份、时序、状态与观察依据，对下一步行动和完成判断可能具有不同价值。已有MEM建立了进度摘要与动作策略的结合，MeMento和COMPACT-VA实现了需求或规划目标对齐，LTE提供了对象级证据与查询路由；上一轮的LatentMem、RCR、REFLECT和HiMe又提供了角色定制、验证与事件回查的基础。我们进一步把**同一事实上的成对判断、共享失真后的错误采纳关系，以及按当前完成条件恢复证据的收益与代价**纳入压缩目标和评价，并构建保留来源、身份与时序关系的证据选择或补充机制，与重新生成共享摘要、状态表加检索等方法作同预算比较。新增贡献在于明确哪些压缩在行动上足够、在完成确认上仍缺依据，并据此改进历史表示和证据预算分配。这为已有任务导向压缩增加了可测量的可靠性维度；实际能否降低共同错误、何时值得补证，由受控实验决定。

【推断】在本轮四篇及1015四篇笔记所覆盖的范围内，尚未看到上述问题、机制与评价链条已被整体完成，因而值得继续发展。贡献可以通过扎实推进已有思想成立。若最后实现仅包含“目标条件摘要＋额外一次问答”，与MeMento及已有验证流程的区分会偏弱；应把实质工作落实到事实级需求、错误关系和预算内证据恢复上。
