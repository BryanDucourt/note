# SSR3D-LLM：基线、数据集和可借鉴的地方（1104）

**起因**：用户 1104 转来这篇（"这篇文章是做空间关系理解的，可以参考一下，另外他们比较的baseline和一些数据集/方法我们也可以参考"）。

**读的是哪一版**：
- 用户转来的 PDF 在微信的文件夹里，macOS 不让 Claude 读。
- Claude 读的是 arXiv 公开版：2605.28490 v1，2026-05-27，CC BY 4.0。NeurIPS 2026 的 poster 页也有这篇。
- 用户手里的文件名带 NeurIPS，可能是会议终版，内容可能和 v1 有出入。

**这篇做什么**：
- 任务是 3D 视觉定位。给一句话，比如"房间中间、棕色沙发右边那把白椅子"，在 ScanNet 的三维扫描里挑出说的是哪个物体。
- 作者：HKUST 和苏州大学。

## 一、方法（简要）

- **候选**：Mask3D 分出来的物体，固定不变。
- **每个候选的输入**：Mask3D 特征、带朝向的框、可选的 DINOv2 多视角外观特征、预测的类别。
- **主干**：Tiny-Vicuna-1B，只用 LoRA 微调了最后 4 层。
- **做法**：
  - 语言模型先生成 4 步隐藏的"关系推理步骤"；
  - 一个看几何的打分器按顺序读这些步骤，逐步给候选重新排序。
  - 作者的说法是：让语言生成和几何判断分开。
- **中间步骤的监督**：
  - Sr3D 的从标注直接生成；
  - Nr3D、ScanRefer、Multi3DRef 的用 Qwen（vLLM）离线标。
- **语言能力**：同一个模型还做对话、问答、描述，不加推理步骤时和基线差不多。

## 二、数据集

| 数据集 | 考什么 | 规模 | 指标 |
|---|---|---|---|
| Nr3D（ReferIt3D） | 人写的自由描述，从候选物体里挑一个。按两种方式拆：<br>· Easy / Hard：同类干扰物 ≤1 个 / ≥2 个；<br>· 视角相关 / 无关：比如"面对沙发，你右手边的……"就是视角相关 | 训练 28,716，测试 7,485 | 候选里 Top-1 准确率 |
| Sr3D（ReferIt3D） | 按模板生成的描述，5 种关系：水平远近（最近 / 最远）、上下、两者之间、相对朝向（某物的左右前后）、支撑（在……上）。拆法同上 | 训练 65,844，测试 17,726 | 同上 |
| ScanRefer | 从检测出来的候选里定位，框和真值的重合度够才算对 | — | Acc@0.25 / Acc@0.50 |
| Multi3DRef | 一句话可能对应多个物体 | — | F1@0.25 / F1@0.50 |
| ScanQA、Scan2Cap、物体描述、对话 | 只用来检查语言能力有没有退步 | — | EM、CIDEr |

- Easy/Hard 和视角相关的定义、Sr3D 的 5 种关系，来自 ReferIt3D 的原文和综述，不在这篇正文里。见文末来源。
- 关于候选：这篇写的是 "official ReferIt3D sets or Mask3D proposals after benchmark matching"。ReferIt3D 原来的设定是直接给出场景里的物体，只考挑哪一个；ScanRefer 则要自己检测。

## 五、和我们有关的地方（Claude 整理，只列事实和对应关系）

1. **把"认东西"和"懂关系"分开测**：Nr3D、Sr3D 给出候选物体，只考挑哪一个；ScanRefer 要自己检测。这和我们讨论过的"离线诊断能不能用真值关系"、识别过不了线时"先用仿真分割当理想识别"是同一个思路。用不用由用户定，涉及 `AGENTS.md`。
2. **分析时可以按两个维度拆**：
   - 有没有同类干扰物，比如图里有好几个柜子；
   - 关系是不是相对观察者的。我们问的"够不够得着、挡没挡、看不看得见"都以机器人身体为参照，最接近他们的"视角相关"一类。
3. **输入形式的先例**：
   - VLM-Grounder：现成的检测加 SAM 标出物体，交给 GPT-4V。和我们"现成识别模型标编号"一样。
   - SeeGround：图加上用文字写的空间信息。和我们差距测量的条件 B（编号旁边写距离）一样。
   - GPT4Scene：俯视图上画和画面一致的编号，对应我们搁置的"俯视图"。另外，GPT4Scene 原文说，用这种带标记的数据训练过的小模型，推理时去掉标记也会变好（来自检索摘要，Claude 没读原文）。
4. **Sr3D 的模板生成**：从标注自动生成 5 类关系的描述。以后做简单测试集时，可以照这个方式，从仿真真值自动生成"身体—物体"关系的问题。测哪些关系，由用户和导师起草。
5. **训练小模型的一种做法**：
   - 1B 模型一次给不准，就先生成几步结构化的关系中间步骤，再由几何打分器挑候选；
   - 中间步骤的监督可以从标注直接生成。我们的仿真真值也能直接生成这类监督。
   - 如果差距测完要训练小模型，可以参考。
6. **不冲突**：他们研究静态扫描里物体和物体的关系，用来指认物体；我们研究机器人身体和物体的关系，用来决定下一步动作。他们把闭环具身使用列为以后的工作。

## 六、可借鉴的设计（Claude 1104，用户问"对我们来说能参考什么设计"，等用户看）

**数据集本身用不上**：都是静态扫描，没有机器人身体。能借的是三样：测试怎么设计、结果怎么拆、方法思路。

**按难度拆开的数**（论文表 1 的 Nr3D、表 7 的 Sr3D）：

| 方法 | Easy / Hard | 视角相关 / 无关 |
|---|---:|---:|
| SPAZER（GPT-4o，不训练） | 68.0 / 58.8 | 59.9 / 66.2 |
| SeeGround（Qwen2-VL-72B，不训练） | 54.5 / 38.3 | 42.3 / 48.2 |
| VLM-Grounder（GPT-4V，不训练） | 55.2 / 39.5 | 45.8 / 49.4 |
| SSR3D-LLM（1B，训练过） | 61.0 / 39.9 | 46.5 / 52.1（Sr3D 上 53.3 / 70.0） |
| MiKASA（专门训练） | 69.7 / 59.4 | 65.4 / 64.0（Sr3D 上 70.4 / 75.4） |

- 同类干扰物多的题（Hard），所有方法都掉 9–21 分。
- 不训练的 VLM 方法，视角相关的题低 3.6–6.3 分；Nr3D 上 MiKASA 不掉。

**可以借的设计**：

| 他们的设计 | 我们可以怎么用 | 回答什么问题 | 什么时候 |
|---|---|---|---|
| 两条赛道：Nr3D / Sr3D 给出物体只考挑哪个；ScanRefer 要自己检测 | 差距测量多跑一组"理想编号"，编号来自仿真分割，和识别模型的编号对比 | 差距里多少来自认东西，多少来自懂关系 | 差距测量之后。涉及 `AGENTS.md`，用户定 |
| 按 Easy / Hard、视角相关 / 无关拆开报 | 每个点打两个标签：<br>· 图里有没有同类干扰物；<br>· 关系以身体为参照（太远、太高、太低、看不见），还是以物体为参照（门关着、被挡） | 模型是不是专在以身体为参照的关系上出错 | 现在。只改计分和报告 |
| Sr3D 按模板从标注自动出题，每题带关系类型 | 简单测试集按 why_not 那几类关系，从仿真真值自动出题，各类数量配平。有资料统计 Sr3D 约八成是"最近 / 最远"一类 | 每一类关系分别差多少 | 用户和导师起草测试集时 |
| 输入的三种给法：图上标编号（VLM-Grounder）、加文字空间信息（SeeGround）、俯视图上标一致的编号（GPT4Scene） | 依次对应条件 A、条件 B、搁置的俯视图，合起来是一个"上下文阶梯" | 每多给一层上下文，决策好多少（1027 的问法） | A、B 已经在做；俯视图等条件 B 有结果 |
| SSR3D：小模型先写几步结构化的关系判断，再由几何打分器做最后选择，不让自由生成的文字直接定答案 | 模型输出结构化的关系判断，由按几何算的模块或者训练出的小打分器变成动作。监督可以从仿真真值直接生成 | 针对"说对了但没做对"：BEHAVIOR 卡住时说得出挡路物 24/25、往空地走最多 11/25；1031 把认对的事实送回规划器也没变好 | 差距测量里"说对了但没做对"占大头时 |
| 大模型调几何工具算关系（ZSVG3D、SORT3D） | 给规划器一个用深度和身体模型算"够不够得着"的工具，和让它自己看图判断对比 | 差在不会算几何，还是会算了也用不上 | 同上 |
| 基线分三类：专门训练的、不训练直接用大模型的、训练过的小模型 | 对应：GPT-6 直接用、Qwen3-VL-8B 直接用、训练过的小模型（自己训的，或 RoboBrain 2.5 等现成具身模型），再加"大模型 + 几何工具" | 写论文时的对比表 | 写论文时 |
