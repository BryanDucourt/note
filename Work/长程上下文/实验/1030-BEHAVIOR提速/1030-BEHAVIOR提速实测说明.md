## 一、做法

1. **计时，不改行为**：
   - 用固定的动作脚本，不调规划器。在起点 8 和起点 108 各跑一组，依次是：
     - scan；
     - rotate_base 向左 40°；
     - move_to_point 走 1.0 m；
     - move_base 前进 0.4 m；
     - move_base 向左 0.3 m。
   - 起点 108 那组要包含被挡停的情况。
   - 记下每个物理步里各部分的耗时：物理步本身、每个相机的渲染、深度读回和保护计算、拍图和编码、评估截图、视频录制（如果有）、日志写入。
   - 报告每一部分的总耗时和占比。
2. **拆分试验，做成开关，默认关闭**：
   - 移动和转身的过程中，每隔 N 个物理步才渲染一次头部相机、做一次保护计算，中间的步只走物理。N 取 1（就是现状）、2、4、8。
   - 动作过程中不用的相机不渲染。v2 只给规划器头部图，如果手上的相机每一步都在渲染，就停掉。
   - 开关关闭时，行为和输出要和现在逐字节相同。
3. **等价检查**：每个 N 都重跑同一组脚本，和现状比较这几项：
   - 每个动作的停止原因；
   - 实际走的距离和转的角度；
   - 结束时的位姿；
   - 最后拍的那张头部图。

   停止原因相同、位姿差在 2 cm 和 1° 以内，才算等价。起点 108 那次被挡的动作，必须照样停下来，而且停下时离障碍不能比现状更近。
4. **显存**：记下每种设置下的显存峰值。
