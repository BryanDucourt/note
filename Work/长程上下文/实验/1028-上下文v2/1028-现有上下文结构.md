**一步之内的流程**：
1. 程序把系统提示、输入 JSON 和图片一起发给模型；
2. 模型返回一个 JSON；
3. 程序处理这个 JSON：
   - 执行 tool 和 arguments；
   - 冻结 check_conditions，动作后交给判断模块核对；
   - 保存 search_plan；
   - 记下 subgoal、reason 和 expected_outcome；
4. 这些内容会出现在下一步的输入里：
   - subgoal 变成 current_subgoal；
   - subgoal、reason、expected_outcome 进入 recent_tools[].planner_intent；
   - search_plan 变成 last_search_plan；
   - 核对结果写进 memory.task。
