# C. Embodied and robot LLM agents: memory reliability, and when to re-observe, verify or ask for help (novelty check for Paper 1)

How to read the entries. Each work gives authors (year), venue, link, a one-sentence method and finding, then four flags: **ME** = studies memory errors; **DUP/PROV** = duplicated or same-source evidence, or provenance of stored facts; **VER** = measures or controls a verify / re-observe / ask decision; **Overlap** with the Paper 1 claim and the key difference. Overlap scale: **High** = tests the same mechanism (duplicated or same-source evidence, then confidence, then checking); **Medium** = shares at least two core pieces of the claim (memory errors that persist, provenance or confidence of stored facts, verification or re-observation decisions); **Low** = shares at most one. Unless marked otherwise, each item was checked against its arXiv abstract (pulled through the arXiv API on 2026-10-21). Items taken only from a search snippet or from my background knowledge are marked "unverified". Papers already in the notes (FailBench, ProgressCompass, MobiAgent, AGM, When Memory Lies, Mind Palace, Remember with Confidence) appear only in overlap comparisons and are not restated.

## Q1. Do robots or embodied LLM agents that decide when to ask for help or re-check from uncertainty (KnowNo-style conformal prediction, introspective planning, "explore until confident" EQA) involve memory errors or duplicated evidence?

### Takeaway
No. About 20 works were checked. In all of them, uncertainty comes from what the user meant, from scores on plan options, or from how confident the VLM is in an answer. None injects memory errors, duplicates evidence or labels provenance. Two things in this group are useful to Paper 1: calibrated "ask" and "stop" baselines, and trade-off curves of help rate against success. Those curves are the closest existing analogue of a sweep over verification costs.

### Cited Findings
Conformal or calibrated asking (no memory involved):
- **KnowNo: Robots That Ask For Help: Uncertainty Alignment for LLM Planners.** Allen Z. Ren, Anushri Dixit, Alexandra Bodrova, Sumeet Singh, Stephen Tu, Noah Brown, Peng Xu, Leila Takayama et al. (2023), CoRL 2023 (oral). Conformal prediction over an LLM planner's candidate next steps gives statistical guarantees on task completion while keeping human help to a minimum. Tested in simulated and real robot setups with spatial, numeric, preference and Winograd-style ambiguity. ME no; DUP/PROV no; VER: controls asking for help. **Overlap: Low.** The uncertainty is about what the user meant, not about whether remembered evidence is true. — [arXiv:2307.01928](https://arxiv.org/abs/2307.01928)
- **Introspective Planning: Aligning Robots' Uncertainty with Inherent Task Ambiguity.** Kaiqu Liang, Zixu Zhang, Jaime Fernández Fisac (2024), NeurIPS 2024. Builds a knowledge base of introspective reasoning examples (post-hoc rationales for human-selected safe plans) and retrieves from it at deployment. Combined with conformal prediction, this gives tighter confidence bounds and fewer unneeded clarification requests. ME no (the retrieved knowledge base is assumed correct); DUP/PROV no; VER: controls asking. **Overlap: Low.** The agent has a retrieval memory, but it is never corrupted or duplicated. — [arXiv:2402.06529](https://arxiv.org/abs/2402.06529)
- **LBAP: Improved Uncertainty Alignment of LLM Planners using Bayesian Inference.** James F. Mullen, Dinesh Manocha (2024, revised 2025), arXiv (venue not checked). Bayesian inference that combines scene grounding with world knowledge calibrates the robot's confidence. In real-world tests it cuts prior methods' human-help rate by over 33% at a 70% success rate. VER: controls asking. **Overlap: Low.** — [arXiv:2403.13198](https://arxiv.org/abs/2403.13198)
- **HERACLEs: Conformal Temporal Logic Planning using LLMs.** Jun Wang, Jiaming Tong, Kaiyuan Tan, Yevgeniy Vorobeychik, Yiannis Kantaros (2023), accepted at ACM Transactions on Cyber-Physical Systems (per the arXiv comment). Conformal prediction is the interface between a symbolic LTL planner and an LLM that writes action sequences, reaching user-defined mission success rates. **Overlap: Low.** — [arXiv:2309.10092](https://arxiv.org/abs/2309.10092)
- **S-ATLAS: Probabilistically Correct Language-based Multi-Robot Planning using Conformal Prediction.** Jun Wang, Guocheng He, Yiannis Kantaros (2024), arXiv (venue not checked). Distributed conformal prediction lets each robot act when it is sure enough and ask for help otherwise. It meets the target success rate with fewer help requests, and the advantage grows with team size. **Overlap: Low.** It is multi-robot, but has no shared-memory errors. — [arXiv:2402.15368](https://arxiv.org/abs/2402.15368)
- **KnowLoop: Evaluating Uncertainty-based Failure Detection for Closed-Loop LLM Planners.** Zhi Zheng, Qian Feng, Hang Li, Alois Knoll, Jianxiang Feng (2024), ICRA 2024 workshop. An MLLM failure detector's uncertainty decides whether to ask a human. Token probability and entropy track failures better than self-explained (verbalized) confidence, and setting a threshold improves failure-detection accuracy. VER: a threshold controls asking. **Overlap: Low.** It is useful evidence that verbalized confidence is a weak trigger for checking. — [arXiv:2406.00430](https://arxiv.org/abs/2406.00430)
- **CLARA: Classifying and Disambiguating User Commands for Reliable Interactive Robotic Agents.** Jeongeun Park, Seungwon Lim, Joonhyung Lee, Sangbeom Park, Minsuk Chang, Youngjae Yu, Sungjoon Choi (2023), arXiv (venue not checked). LLM uncertainty sorts commands into clear, ambiguous or infeasible, and the robot asks questions to resolve ambiguous ones. **Overlap: Low.** — [arXiv:2306.10376](https://arxiv.org/abs/2306.10376)
- **CommCP: Efficient Multi-Agent Coordination via LLM-Based Communication with Conformal Prediction.** Xiaopan Zhang, Zejin Wang, Zhixu Li, Jianpeng Yao, Jiachen Li (2026), ICRA 2026. In multi-agent multi-task EQA, conformal prediction calibrates the LLM messages robots send each other so they distract the receiver less, which improves success and exploration efficiency. DUP/PROV: partly (it is about how reliable messages from other agents are, not about duplicates). **Overlap: Low.** It is the conformal-prediction work closest to "information arriving from several sources". — [arXiv:2602.06038](https://arxiv.org/abs/2602.06038)

EQA "explore until confident" (memory exists but is treated as correct):
- **Explore until Confident: Efficient Exploration for Embodied Question Answering.** Allen Z. Ren, Jaden Clark, Anushri Dixit, Masha Itkina, Anirudha Majumdar, Dorsa Sadigh (2024), RSS 2024. Builds a semantic map from depth plus VLM visual prompting, then uses conformal prediction to calibrate the VLM's answer confidence so the robot knows when to stop exploring. The paper names miscalibrated VLM confidence as the cause of stopping too early or exploring too long. VER: controls when to stop gathering information. **Overlap: Low** (the closest work in Q1). The logic matches Paper 1 (overconfidence makes the robot stop gathering too soon), but the confidence error comes from the VLM, not from memory structure, and map content is never corrupted. — [arXiv:2403.15941](https://arxiv.org/abs/2403.15941)
- **EfficientEQA.** Kai Cheng, Zhengyuan Li, Xingpeng Sun, Byung-Cheol Min, Amrit Singh Bedi, Aniket Bera (2024), IROS 2025 (oral). Frontier exploration is weighted by a black-box VLM's verbalized confidence, with a relevance-based rule for stopping and RAG over past observations. It gets over 15% higher accuracy with over 20% fewer steps. **Overlap: Low.** — [arXiv:2410.20263](https://arxiv.org/abs/2410.20263)
- **GraphEQA.** Saumya Saxena, Blake Buchanan, Chris Paxton, Peiqi Liu, Bingqing Chen, Narunas Vaskevicius, Luigi Palmieri, Jonathan Francis et al. (2024), arXiv (venue not checked). Real-time 3D metric-semantic scene graphs plus task-relevant images serve as multimodal memory for a VLM planner that explores until it can answer with confidence. It completes more tasks in fewer steps on HM-EQA and OpenEQA. **Overlap: Low.** — [arXiv:2412.14480](https://arxiv.org/abs/2412.14480)
- **3D-Mem.** Yuncong Yang, Han Yang, Jiachen Zhou, Peihao Chen, Hongxin Zhang, Yilun Du, Chuang Gan (2024), arXiv (venue not checked). "Memory Snapshots" (multi-view images) plus "Frontier Snapshots" let the agent weigh what it knows against what it might find. **Overlap: Low.** — [arXiv:2411.17735](https://arxiv.org/abs/2411.17735)

Learned or prompted asking with an explicit cost:
- **Ask4Help: Learning to Leverage an Expert for Embodied Tasks.** Kunal Pratap Singh, Luca Weihs, Alvaro Herrasti, Jonghyun Choi, Aniruddha Kembhavi, Roozbeh Mottaghi (2022), NeurIPS 2022. A learned policy decides when to ask an expert, trading task performance against the amount of help. ObjectNav success rises from 52% to 86% with 13% help, and rearrangement from 7% to 90.4% with 39% help. VER: controls asking, with a cost trade-off. **Overlap: Low.** It is the closest existing "cost of checking" curve in embodied AI, but the thing consulted is an expert, not memory. — [arXiv:2211.09960](https://arxiv.org/abs/2211.09960)
- **A Framework for Learning to Request Rich and Contextually Useful Information from Humans.** Khanh Nguyen, Yonatan Bisk, Hal Daumé III (2021), ICML 2022. A learned policy for requesting help in simulated human-assisted navigation achieves up to 7x the success of fully autonomous behaviour in unseen environments. **Overlap: Low.** — [arXiv:2110.08258](https://arxiv.org/abs/2110.08258)
- **Ask-to-Act: Grounding Multimodal LLMs to Embodied Agents that Ask for Help with RL.** Ram Ramrakhya, Matthew Chang, Xavier Puig, Ruta Desai, Zsolt Kira, Roozbeh Mottaghi (2025), arXiv (venue not checked). An MLLM is fine-tuned with online RL, using LLM-generated rewards, to ask a few clarification questions during rearrangement under partial observability. It beats GPT-4o and supervised baselines by 10.4–16.5%. **Overlap: Low.** — [arXiv:2504.00907](https://arxiv.org/abs/2504.00907)
- **Asking Before Acting (ABA).** Xiaoyu Chen, Shenao Zhang, Pushi Zhang, Li Zhao, Jianyu Chen (2023), arXiv (venue not checked). LLM agents ask external sources questions in natural language before acting, which improves performance and efficiency on text household tasks, robot-arm tasks and real-image embodied tasks. **Overlap: Low.** — [arXiv:2305.15695](https://arxiv.org/abs/2305.15695)
- **ReDAct: Uncertainty-Aware Deferral for LLM Agents.** Dzianis Piatrashyn, Nikita Kotelevskii, Kirill Grishchenkov, Nikita Glazkov, Ivan Nasonov, Ilya Makarov, Timothy Baldwin, Preslav Nakov et al. (2026), arXiv. A small LLM hands a decision to a large one when its predictive uncertainty passes a calibrated threshold. On ALFWorld and MiniGrid, deferring about 15% of decisions matches the large model alone. VER: controls a costed check. **Overlap: Low.** — [arXiv:2604.07036](https://arxiv.org/abs/2604.07036)
- **PCE: From Assumptions to Actions.** SeungWon Seo, SooBin Lim, SeongRae Noh, Haneul Kim, HyeongYeop Kang (2026), ICLR 2026. Turns the assumptions hidden in LLM reasoning into a decision tree, scoring each path by scenario likelihood, goal gain and execution cost. This reduces costly communication between agents on C-WAH and TDW-MAT. **Overlap: Low.** — [arXiv:2602.04326](https://arxiv.org/abs/2602.04326)

Calibration measured in embodied agents:
- **Uncertainty in Action: Confidence Elicitation in Embodied Agents.** Tianjiao Yu, Vedant Shah, Muntasir Wahed, Kiet A. Nguyen, Adheesh Juvekar, Tal August, Ismini Lourentzou (2025), arXiv. Policies for eliciting and acting on confidence in Minecraft. Structured reasoning such as chain-of-thought improves calibration and failure prediction, but telling apart sources of uncertainty stays hard, especially in abductive settings. VER: measures calibration only. **Overlap: Low.** — [arXiv:2503.10628](https://arxiv.org/abs/2503.10628)

### Inferences
- In this group, the "ask" goes to a human and is about task intent. In Paper 1, the "check" goes to the world (look again). No work found treats checking oneself by re-observing as the action being calibrated.
- The help-rate versus success curves in KnowNo, LBAP and Ask4Help give a familiar way to plot Paper 1's results: verification cost on the x-axis, and verification rate plus error persistence on the y-axis.
- Explore until Confident and GraphEQA stop exploring based on maps or scene graphs that a VLM writes. A misperception copied into such a map would feed straight into their stopping rule. This failure mode is untested (inference).
- Relation to the notes: Mind Palace's value-of-information stopping rule is still the closest "when to stop gathering" rule that involves memory. No new work in this group adds corrupted memory.

### Gaps
- Full texts of the KnowNo-family papers were not read, so an appendix that perturbs scene descriptions or memory could have been missed. The abstracts mention none.
- Venues for GraphEQA, 3D-Mem, LBAP, S-ATLAS, CLARA, Ask-to-Act and ABA were not checked; the arXiv metadata gives none.

## Q2. Do embodied memory systems that track provenance, confidence or staleness (Remember with Confidence, Mind Palace, ReMEmbR, Embodied-RAG, scene-graph memories with uncertainty) measure what happens when the same wrong fact is stored more than once?

### Takeaway
No embodied memory paper found puts the same wrong fact into memory more than once, or into several stores, and measures the effect. The closest embodied works do one of three things:
- keep provenance (OpenBelief-Nav keeps the phrase from each observation and which frame and mask it came from);
- test source monitoring and false-memory lures as retrieval probes (eMEM);
- attach a confidence to each claim (BeliefMem, Agent-BRACE).

The duplicated-evidence mechanism itself has been measured directly, but only in non-embodied LLM systems, in September and October 2026: "Copies or Sources?" and GraphEcho. These two are the main collision risk for Paper 1's mechanism claim.

### Cited Findings
Embodied memory with provenance, confidence or preserved evidence:
- **OpenBelief-Nav: Evidence-Preserving Object Memory for Open-Vocabulary Language-Guided Navigation.** Dinh Tuan Nguyen, Anh Dao, Phuong Nam Dang, Quan-Dung Pham, Tuyen P. Le, Truong Nguyen, Quan Nguyen (2026), arXiv. An open-vocabulary scene-graph memory keeps the phrase from each observation, reliability cues and frame-mask provenance, instead of committing to one fused label.
  - On HM3D-YCB navigation, belief-weighted retrieval succeeded in 58/78 trials, against 60/78 for consensus and early-commit retrieval.
  - On a Unitree G1, allowing at most two verified candidate attempts raised target confirmation from 6/10 to 8/10.

  ME: partly (early commitment drops minority hypotheses); PROV: yes, stored; VER: controls a bounded verify-and-retry. **Overlap: Medium.** It is the closest embodied work that combines provenance-keeping memory with verification. Differences: provenance is used for retrieval, not for discounting confidence; duplicates are not manipulated; the planner is not an LLM whose calibration is measured; and the verification budget is fixed, not swept. — [arXiv:2608.13923](https://arxiv.org/abs/2608.13923)
- **eMEM: A Hybrid Spatio-Temporal Memory System for Embodied Agents.** A. Haroon Rasheed, Maria Kabtoul (2026), arXiv. A graph memory with structured, semantic and spatial indexes and staged consolidation, plus eMEM-Bench on ProcTHOR-10K. The benchmark has eight probes taken from cognitive psychology, including DRM false-memory lures and source monitoring. eMEM scores a weighted mean of 80.8 over 988 probes, and a flat-RAG ablation loses 29 points on rejecting DRM lures. ME: yes (false-memory lures); PROV: yes (source-monitoring probes); VER: no. **Overlap: Medium.** It tests whether memory can tell sources apart, but only as retrieval probes: there is no planner, no copy count and no verification choice. — [arXiv:2606.03374](https://arxiv.org/abs/2606.03374)
- **WorldLines: Benchmarking and Modeling Long-Horizon Stateful Embodied Agents.** Yehang Zhang, Jianchong Su, Haojian Huang, Yifan Chang, Tianhao Zhou, Xinli Xu, Yingjie Xu, Yinchuan Li et al. (2026), EMNLP 2026. Turns long household traces into samples linked to their evidence, for memory QA and embodied task planning. Its ObsMem model keeps memories that record what was visible and state trails tied to actions. Partial observability and overwritten world states remain hard. ME: yes (stale or overwritten states); PROV: partial (evidence links, visibility); VER: no. **Overlap: Medium (lower end).** — [arXiv:2606.18847](https://arxiv.org/abs/2606.18847)
- **MeMoREval: What Should Embodied Agents Remember?** Junxiang Wang, Yuchen Liu, Yi Wu, Guofei Chen, Nir Pechuk, Tao Chen, Zackory Erickson, Yuzhe Qin et al. (2026), arXiv. Agents first experience events, then answer requests from memory alone, across 53 tasks in four simulated indoor environments. Storing frames beats storing generated descriptions, at lower write-time cost, and frames plus scene graphs give the best overall success for every model tested. **Overlap: Low.** It is still the closest evidence that memory text written by an LLM is worse than raw evidence, and LLM-written text is how Paper 1's single-call copying happens. — [arXiv:2610.12561](https://arxiv.org/abs/2610.12561)
- **Belief Memory (BeliefMem): Agent Memory Under Partial Observability.** Junfeng Liao, Qizhou Wang, Jianing Zhu, Bo Du, Rui Yan, Xiuying Chen (2026), arXiv. Argues that storing one fixed conclusion per observation causes "self-reinforcing error": the agent acts on the stored conclusion, never revisits alternatives, and reinforces it. BeliefMem instead stores several candidate conclusions with probabilities, updates them with Noisy-OR rules, and shows them together at retrieval. It has the best average performance on LoCoMo and ALFWorld. ME: yes (self-reinforcing); PROV: confidence yes, duplicates no; VER: no. **Overlap: Medium.** It names the persistence loop Paper 1 targets, but does not vary copies or provenance, and its Noisy-OR rule counts each new observation as independent support. — [arXiv:2605.05583](https://arxiv.org/abs/2605.05583)
- **Agent-BRACE.** Joykirat Singh, Zaid Khan, Archiki Prasad, Justin Chih-Yao Chen, Akshay Nambi, Hyunji Lee, Elias Stengel-Eskin, Mohit Bansal (2026), arXiv. Splits an LLM agent into a belief model and a policy, trained with RL. The belief is a set of short claims, each with a verbalized certainty label from "certain" to "unknown". In partially observable embodied language environments it gains 14.5 points (Qwen2.5-3B) and 5.3 points (Qwen3-4B), and the belief gets better calibrated as evidence builds up. **Overlap: Low.** It offers a calibrated format for belief memory, not a duplication study. — [arXiv:2605.11436](https://arxiv.org/abs/2605.11436)
- **EmbodiedMemory-Bench (EMem-Bench).** Lizhou Liang, Xinyu Zhong, Miao Pan, Xiaohe Zhou, Xuanyu Liu, Qinfeng Li, Peng Li, Jintao Chen et al. (2026), arXiv. 2,554 interactive episodes across four task families. It traces memory failures to four weaknesses: fine-grained visual memory, tracking a changing world state, failing to record state revealed by interaction outcomes, and generalizing from past experience. ME: yes, naturally occurring; DUP/VER: no. **Overlap: Low.** — [arXiv:2609.28236](https://arxiv.org/abs/2609.28236)

Multi-store embodied memories, where one perception can be written to several stores. This is the Paper 1 setting, and none of these analyses copying across stores:
- **RoboMemory.** Mingcong Lei, Honghao Cai, Yuyuan Yang, Yimou Wu, Jinke Ren, Zezhou Cui, Liangchen Tan, Junkun Hong et al. (2025; v7 2026), arXiv. Spatial, Temporal, Episodic and Semantic memory run in a parallel architecture with a dynamic spatial knowledge graph and a planner with a critic. Average success on EmbodiedBench rises 26.5% over a Qwen2.5-VL-72B baseline. **Overlap: Low (setting match).** — [arXiv:2508.01415](https://arxiv.org/abs/2508.01415)
- **MEMORA.** Zihao Yu, Xiu Yuan, Chongjie Zhang (2026), EMNLP 2026 (per the v2 comment). Environment, Entity, Activity and Inferred-Knowledge stores are edited online as new evidence arrives and consolidated offline into routines from repeated experience. It improves a robot-grounded plan score by up to 16.6% on a 45-hour suite of egocentric videos. **Overlap: Low (setting match).** — [arXiv:2607.14252](https://arxiv.org/abs/2607.14252)
- **LongAct / HoloMind: When Robots Do the Chores.** Zilin Zhu, Longteng Guo, Yanghong Mei, Bowen Pang, Zongxun Zhang, Xingjian He, Ruyi Ji, Jing Liu (2026), arXiv. HoloMind combines a DAG planner, multimodal spatial memory, episodic memory and a global critic. On LongAct, even top models reach only 59% goal completion and 16% full-task success. **Overlap: Low (setting match).** — [arXiv:2605.14504](https://arxiv.org/abs/2605.14504)
- **KARMA.** Zixuan Wang, Bo Yu, Junzhe Zhao, Wenhao Sun, Sai Hou, Shuai Liang, Xing Hu, Yinhe Han et al. (2024), arXiv (venue not checked). Long-term memory is a 3D scene graph; short-term memory records changes in object position and state, with adaptive replacement. Success is 1.3x and 2.3x the baselines on AI2-THOR composite and complex tasks. **Overlap: Low.** — [arXiv:2409.14908](https://arxiv.org/abs/2409.14908)
- **Mosaic.** Kunjal Panchal, Saayan Mitra, Sunav Choudhary, Victor Bursztyn, Somdeb Sarkhel, Hui Guan (2026), ICML 2026. Finds that failed actions, caused by inaccurate state tracking under partial observability, are the main source of delay in multi-agent embodied planning. An agent-centric semantic memory plus ILP allocation runs 27–32% faster with 4–10 points higher success. **Overlap: Low.** — [arXiv:2607.09603](https://arxiv.org/abs/2607.09603)

- **EmbodiedLGR.** Paolo Riva, Leonardo Gargani, Matteo Frosi, Matteo Matteucci (2026), IROS 2026. A semantic graph built by a VLM plus RAG; fast queries on NaVQA; runs on a real robot. — [arXiv:2604.18271](https://arxiv.org/abs/2604.18271)

- **DM³-Nav.** Amin Kashiri, Atharva Jamsandekar, Yasin Yazıcıoğlu (2026), IROS 2026. Robots swap local maps and goal status in pairs, without a global map, and match centralized baselines. **Overlap: Low.** Re-shared map content could be counted twice in this setting; the paper does not analyse it. — [arXiv:2604.22014](https://arxiv.org/abs/2604.22014)
- **Observe, Share, or Predict?** Adrián Szlatincsán, Filippo Ziliotto, Bruno Lepri, Luciano Serafini, Massimiliano Luca, Tommaso Campari (2026), arXiv. On PARTNR, swapping object knowledge between co-located agents mostly saves steps (up to 25%) with little change in success. Predicting the partner's next action lowers success in 15 of 16 model and context pairs. **Overlap: Low.** — [arXiv:2610.16895](https://arxiv.org/abs/2610.16895)

Non-embodied works that test duplicated or same-source evidence directly. These are outside scope C, flagged because they are the main collision risk on the mechanism:
- **Copies or Sources? Measuring How LLM Aggregators Count Restated Evidence in Multi-Agent Systems.** Jianxin Gao, Runze Li, Tianyi Yu, Liangwei Ren, Bohan Chen, Zining Wang (2026-10-05), arXiv. The method converts a reported probability into units of independent readings. This gives each restatement a "copy weight": 0 for an aggregator that counts sources, 1 for one that counts every statement. It also gives the decision implied under any cost structure. Evidence is held fixed while the restatement is varied, in three testbeds: message logs with an exact Bayesian oracle, web documents with copies appended, and logs written by LLM agent teams under four protocols. Findings, across four models from three providers:
  - A forwarded copy counts for 0.06–0.42 of a new reading.
  - On 5–40% of logs that state one reading three times, the reported belief implies an early commitment the oracle never makes.
  - A one-paragraph statement of what a copy contributes brings the copy weight to 0.08 or less.
  - A rule that has agents refer to readings instead of restating them cuts belief-implied early commitment from 11.2% to 1.1%.

  **Overlap: High (mechanism).** It uses the same causal design (fixed evidence, varied copies) and the same kind of outcome (overconfidence leading to early commitment, decisions that depend on cost). Differences: no embodiment, no memory stores, no images, no physical re-observation, no progress judgments, and the copies come from relays and shared boards rather than from the agent's own memory writer. — [arXiv:2610.06192](https://arxiv.org/abs/2610.06192)
- **GraphEcho: Structural Redundancy and Evidence Provenance in LLM Graph Agents.** Sikun Wang, Yixi Zhou, Lei Fan, Fan Zhang (2026-09-15), arXiv. Varies how many graph paths lead to evidence and how many independent origins there are, holding the evidence content fixed, and scores both the agents' judgments and their active exploration. How judgments shift depends on the model, but redundant supporting paths increase repeated walks for every frozen agent tested. Provenance-aware post-training cuts revisits but reaches fewer distinct sources, and on scientific claims accuracy drops. **Overlap: High (mechanism).** It varies copies and provenance with content fixed, and measures the effect on information gathering. Differences: graph agents, no embodied memory, no costed re-observation. — [arXiv:2609.17695](https://arxiv.org/abs/2609.17695)
- **CAGE-CAL: Counterfactual Graph for Multi-Agent LLM Calibration.** Jiatan Huang, Mingchen Li, Ziming Li, Sunjae Kwon, Hong Yu, Chuxu Zhang (2026), arXiv. Shows that agreement among agents after they communicate can reflect correlated failures and false consensus, and calibrates confidence against a matched graph with no communication. **Overlap: Medium.** It calibrates for dependence between sources, but is non-embodied and has no memory. — [arXiv:2605.30653](https://arxiv.org/abs/2605.30653)
- **EAL-Bench: Agent Memory Is a Surface for Endogenous Authorization Laundering.** Tommaso Cerruti, Mika Okamoto, Ansel Kaplan Erol (2026), arXiv. Under incremental updates, LLM memory writers create false authority for up to 50.2% of unauthorized requests, and executors act on that false authority in 98.6% of trials. One safeguard requires each stored permission to be backed by a valid source event. **Overlap: Medium.** The memory errors are self-generated and their provenance is "washed away", and the writer/executor split mirrors Paper 1's writer/planner. It is non-embodied and has no copy count or verification cost. — [arXiv:2609.01836](https://arxiv.org/abs/2609.01836)
- **Governed Shared Memory for Multi-Agent LLM Systems.** Yanki Margalit, Nurit Cohen-Inger, Erni Avram, Ran Taig, Oded Margalit (2026), arXiv. Names four failure modes of memory shared by a fleet of agents: unauthorized leakage, stale propagation, contradiction persistence and provenance collapse. Its provenance tracking rebuilt 100% of four-step derivation chains, and a near-duplicate filter could wrongly reject contradicting writes. **Overlap: Low.** It is a systems paper with no study of agent behaviour. — [arXiv:2606.24535](https://arxiv.org/abs/2606.24535)
- **A-MemGuard.** Qianshan Wei, Tengchao Yang, Yaochen Wang, Xinfeng Li, Lijun Li, Zhenfei Yin, Yi Zhan, Thorsten Holz et al. (2025), arXiv. Memory attacks start a "self-reinforcing error cycle" in which the corrupted outcome is stored as a precedent. The defense compares reasoning paths built from several related memories (consensus-based validation) and keeps a separate memory of lessons; it cuts attack success by over 95%. **Overlap: Medium.** It names error cycles and uses agreement among memories as its check, which same-source copies could fool (see Inferences). It is non-embodied. — [arXiv:2510.02373](https://arxiv.org/abs/2510.02373)

Classical robotics analogue (double counting in decentralized fusion):
- **Funk, Dagan, Noack, Ahmed (2023). Exploiting Structure for Optimal Multi-Agent Bayesian Decentralized Estimation.** RSS 2023 workshop (IDMAV). Calls "rumor propagation" or "double counting", where previously sent data comes back to its sender, a key challenge in Bayesian decentralized fusion. Covariance intersection avoids it but is often over-conservative; the paper derives tighter bounds by using the independence structure. **Overlap: Low (conceptual precedent).** It is the estimation-theory form of "same-source evidence counted twice". — [arXiv:2307.10594](https://arxiv.org/abs/2307.10594)

### Inferences
- So far, embodied memory papers handle unreliable entries by keeping more of the evidence or more of the uncertainty. More evidence: OpenBelief-Nav's provenance, MeMoREval's stored frames, and in the notes, Remember with Confidence's disagreement across views. More uncertainty: BeliefMem, Agent-BRACE. None tracks whether two entries share one origin, and no paper found asks what happens when the same wrong fact sits in several stores.
- Several mechanisms count agreement between entries as support: BeliefMem's Noisy-OR update, A-MemGuard's consensus check, and the fusion of repeated detections in ApexNav and SG-Nav. If those entries come from one source, these rules should inflate confidence. That is the double-counting problem known from decentralized fusion (Funk et al.). This is my inference; none of these papers tests it. It makes them natural baselines or defenses to stress-test in Paper 1.
- Several multi-store embodied architectures make the Paper 1 setting concrete:
  - RoboMemory: four stores updated in parallel;
  - MEMORA: four stores;
  - EMem: spatial, event and scene memories;
  - HoloMind: spatial plus episodic memory.

  This supports the claim that the setting is realistic, but none reports copying across stores.
- The general mechanism, that LLMs count restated evidence as new and so become overconfident and commit early, is no longer open: "Copies or Sources?" (October 2026) and GraphEcho (September 2026) test it with fixed evidence and varied copies or provenance. Paper 1 must cite both. Its novelty then rests on the embodied side:
  - the copies come from the agent's own memory writer (one call writes to several stores);
  - the correcting action is a physical, costly re-observation;
  - the error persists into both progress judgments and next actions.
- The copy weight from "Copies or Sources?", and its decision implied under a cost structure, is a ready-made measure Paper 1 could adopt, or contrast with, for calibration across its cost sweep (inference).
- Relation to the notes: When Memory Lies (a stale memory claim against a contradicting observation) and Remember with Confidence (caption disagreement across views plus budgeted refinement) stay the closest notes. OpenBelief-Nav and eMEM add provenance-keeping and source-monitoring probes, but neither adds a duplication manipulation.

### Gaps
- Full texts of OpenBelief-Nav, eMEM and BeliefMem were not read, so I could not confirm whether they ever test duplicated identical observations. The abstracts do not mention it.
- A search for memory poisoning of physical robots found only the driving agent in AgentPoison and prompt-injection work, not a study of long-term robot memory poisoning.
- Unverified (search snippet only): that Thea's memory consolidation writes only entries above a confidence threshold, and GraphEcho's model list (Qwen3 family, GPT-5-mini).

## Q3. Failure detection, progress monitoring and verification in long-horizon robot tasks: is there any study of error persistence caused by the agent's own memory, or of verification frequency versus confidence?

### Takeaway
Error persistence caused by the agent's own memory or beliefs is documented: experience-following, belief inertia, and BeliefMem's self-reinforcing error (AGM in the notes). In every case it comes from naturally occurring or single erroneous records, never from duplicated or same-source entries. How often to verify is set by fixed thresholds, call caps or always-on steps; no embodied work studies it as an outcome that depends on confidence and cost.

### Cited Findings
Errors that persist through the agent's own memory or beliefs:
- **How Memory Management Impacts LLM Agents: An Empirical Study of Experience-Following Behavior.** Zidi Xiong, Yuping Lin, Wenya Xie, Pengfei He, Zirui Liu, Jiliang Tang, Himabindu Lakkaraju, Zhen Xiang (2025), ACL 2026. When a task closely resembles a retrieved memory record, the agent's output closely resembles that record's output ("experience-following"). This causes error propagation (past mistakes compound) and misaligned experience replay. Full-text details, read via the HTML version:
  - Agents tested: RegAgent, EHRAgent, AgentDriver (nuScenes driving) and CIC-IoT.
  - On AgentDriver, success was 40.11 with fixed memory, 32.32 when every run is added to memory, and 51.00 with strict addition.
  - Propagation is measured against an "error-free" variant that swaps in ground-truth outputs; errors are not injected and duplicates are not varied.

  ME: yes (self-generated); DUP no; VER no. **Overlap: Medium.** It is the strongest evidence that an agent's own stored errors persist and spread. It has no duplication or provenance manipulation and no verification actions, and its only physical domain is driving. — [arXiv:2505.16067](https://arxiv.org/abs/2505.16067); [full text](https://arxiv.org/html/2505.16067v2); [ACL 2026](https://aclanthology.org/2026.acl-long.27.pdf)

### Inferences
- Embodied failure and progress detectors (REFLECT, Sentinel, Code-as-Monitor, AHA, VeGAS) assume the detector reads the world. None tests a detector or planner that reads memory whose content was copied from one misperception. That is where Paper 1's claim that errors spread into progress judgments is new (inference).

- Relation to the notes: AGM stays the closest note (memory turns passing failures into lasting task-state errors). FailBench and ProgressCompass cover how accurately VLMs judge success and progress and how much that depends on context. The new items here (experience-following, EVU, BeliefMem) add evidence that errors persist, but none manipulates duplicates.

## Q4. Active perception and information gathering for verification in embodied agents (value-of-information driven re-observation)

### Takeaway
Looking again to confirm a candidate object is now a standard part of these systems: SG-Nav's re-perception, ReMemNav, the Fast-Slow agent's check before writing to memory, OpenBelief-Nav's verified attempts, and PInVerify. Classical active perception treats it as hypothesis testing with a motion cost (Atanasov et al.). Velez et al. (2012) go further and explicitly model that repeated looks from the same or nearby spots are correlated, not independent. That is the closest robotics precedent for "same-source evidence should not add confidence". No embodied work of the LLM era measures how the structure of remembered evidence (copies, provenance) shifts the decision to look again, or sweeps the cost of looking.

### Cited Findings
Classical:
- **Modelling Observation Correlations for Active Exploration and Robust Object Detection.** Javier Velez, Garrett Hemann, Albert S. Huang, Ingmar Posner, Nicholas Roy (2012), JAIR 44:423–453. An online planner learns how detection accuracy depends on viewpoint and plans motion that maximizes expected detection performance. Its sensor model captures that successive measurements from the same or nearby locations are not independent. Tested on door and text detection indoors, with better detection than alternative methods. ME: misdetections; DUP: yes (correlated repeated observations); VER: controls re-observation, since the robot moves to look again. **Overlap: Medium (conceptual precedent).** It is the closest robotics precedent for "repeated looks from the same place are not new evidence". It has no LLM and no memory copying, and the correlation comes from viewpoint, not from a memory writer. — [DOI 10.1613/jair.3516](https://doi.org/10.1613/jair.3516); [arXiv:1401.4612](https://arxiv.org/abs/1401.4612)
- **Nonmyopic View Planning for Active Object Detection.** Nikolay Atanasov, Bharath Sankaran, Jerome Le Ny, George J. Pappas, Kostas Daniilidis (2013), submitted to IEEE T-RO (per the arXiv comment; published version not checked). Active hypothesis testing, solved as a point-based POMDP, plans views that balance motion energy against the chance of identifying the right hypothesis. It beats greedy view selection and static detection on a PR2. VER: controls re-observation, with a motion cost. **Overlap: Low.** — [arXiv:1309.5401](https://arxiv.org/abs/1309.5401)

LLM and VLM era:
- **SG-Nav.** Hang Yin, Xiuwei Xu, Zhenyu Wu, Jie Zhou, Jiwen Lu (2024), NeurIPS 2024. An LLM reasons over an online 3D scene graph with hierarchical chain-of-thought, and a "re-perception mechanism" lets the navigator correct perception errors. It beats prior zero-shot methods by over 10% success on MP3D, HM3D and RoboTHOR. ME: yes (perception errors in memory); DUP no; VER: controls re-perception. **Overlap: Medium.** It corrects memory errors by looking again, but does not analyse how the structure of stored evidence changes that decision, and has no cost sweep. — [arXiv:2410.08189](https://arxiv.org/abs/2410.08189)
- **Hierarchical Fast-Slow ReAct Agent for Zero-Shot Object-Goal Navigation.** Zhaochen Lan, Zhi Yang, Yuxiang Fu, Mengxiang Lin (2026), arXiv. The agent writes a memory tied to map coordinates: a semantic grid, confirmed object instances, and keyframes tagged with the camera pose. A VLM screens each candidate detection before it is written. A deliberative layer recalls a first-person view only for candidates that text alone cannot tell apart, and caps per call and per run limit its calls. Results: 68.75% success on HM3D v1 val, and choosing among far frontiers by argmax instead of deliberating costs 3.40 success points (95% CI [1.70, 5.05]). A search snippet says the screen vetoes 16.7% of candidate detections (unverified). ME: yes (false detections); PROV: pose-tagged keyframes; VER: controls a check before writing plus capped recall. **Overlap: Medium.** It stops misperceptions before they enter memory and re-checks raw views, but has no duplication manipulation, no calibration measure, and fixed rather than swept budgets. — [arXiv:2608.09816](https://arxiv.org/abs/2608.09816)
- **ReMemNav.** Feng Wu, Wei Zuo, Wenliang Yang, Jun Xiao, Yang Liu, Xinhua Zeng (2026), arXiv. False-positive target predictions cause early stopping, so the agent checks the single-view observation before the final approach and retrieves past scene descriptions to avoid revisits. Success rises by up to 18.2% on HM3D v0.2. **Overlap: Low.** — [arXiv:2603.26788](https://arxiv.org/abs/2603.26788)
- **PInVerify: An Offline Embodied Benchmark for Active Instance Verification.** Yuhang Jiang (2026), CVPR 2026 FMEA workshop (poster). Frames checking whether an object matches a fine-grained description as a finite-horizon decision process: 3,000 episodes, 18 categories, including views that can be reached but show nothing useful. None of the tested next-best-view strategies gave reliable gains, and a LoRA-tuned agent reaches 85.6%. VER: measured (viewpoint choice). **Overlap: Low.** It has no memory and no cost sweep. — [arXiv:2605.30639](https://arxiv.org/abs/2605.30639)
- **Active Perception for Embodied Disambiguation.** Yiwei Liu, Luwei Yang (2026), arXiv. A VLM uses the visual evidence gathered so far to decide whether to keep observing, ask for clarification or commit; real-robot experiments. VER: controls observe, ask or commit. **Overlap: Low.** The three-way choice resembles verify, ask or act, but the evidence is neither duplicated nor drawn from memory. — [arXiv:2608.13605](https://arxiv.org/abs/2608.13605)
- **ActiveArena.** Yibo Li, Enshen Zhou, Rui Chen, Yanjun Ding, Mengzhen Liu, Yi Han, Jiabo Zhan, Lipeng Wang et al. (2026), arXiv. 35 active-perception manipulation tasks that need several rounds of gathering evidence and reasoning from memory, plus 13 VLA configurations for studying how memory is written and how much it holds. More memory capacity helps when the write policy is reliable. **Overlap: Low.** — [arXiv:2609.24124](https://arxiv.org/abs/2609.24124)
- **AP-VLM (Scene Exploration by Vision-Language Models).** Venkatesh Sripada, Samuel Carter, Frank Guerin, Amir Ghalamzan (2024), arXiv. A VLM picks viewpoints on a 3D grid to resolve occluded or tilted objects, on a Franka and a UR5, and beats passive perception. **Overlap: Low.** — [arXiv:2409.17641](https://arxiv.org/abs/2409.17641)
- **OpenBelief-Nav** (see Q2): a bounded number of verified candidate attempts on a humanoid raised target confirmation from 6/10 to 8/10. — [arXiv:2608.13923](https://arxiv.org/abs/2608.13923)

### Inferences
- Velez et al. (2012), with the decentralized-fusion work on double counting, lets Paper 1 present itself as the LLM-memory version of a known robotics problem: evidence that is repeated but not independent. It also supports an oracle that counts sources, not entries (inference).

### Inferences
- Novelty, argued in one paragraph (following the user's norm of developing the idea first). Within embodied and robotics work, Paper 1's design appears to be open. It would take one misperception that the agent's own memory writer copies into several stores (task, object, spatial, experience). It would vary the number of copies and the provenance labels while holding images and context length fixed. It would then measure calibration, the choice to re-observe across a sweep of verification costs, and whether the error persists into progress judgments and next actions, with two or more planner LLMs on BEHAVIOR-1K. The nearest embodied works each cover one slice: provenance-keeping memory with a bounded verification budget (OpenBelief-Nav), source-monitoring probes (eMEM), self-reinforcing memory error (BeliefMem; AGM in the notes), belief inertia with a verify step (EVU), checks before writing and re-perception (Fast-Slow, SG-Nav), and correlated repeated observations in classical active perception (Velez 2012). This is not a collision, but positioning is needed. "Copies or Sources?" and GraphEcho have just shown, outside embodiment, that LLMs count restated evidence and that this produces early commitment and redundant exploration. Paper 1 should therefore present the general effect as recently established and claim three embodied-specific contributions:
  - the copies come from the agent's own memory pipeline, a design pattern common in multi-store embodied agents such as RoboMemory, MEMORA and HoloMind;
  - the verification is a physical action whose cost changes behaviour;
  - errors persist into both progress judgments and actions.
- Ready-made pieces Paper 1 can borrow or compare against:
  - the copy weight and the "refer, don't restate" rule from "Copies or Sources?" (a natural mitigation arm: store one entry plus pointers);
  - the provenance-aware post-training trade-off from GraphEcho (efficiency versus coverage);
  - the Fast-Slow agent's check before writing to memory;
  - BeliefMem's Noisy-OR update and A-MemGuard's consensus check, as defenses likely to be fooled by same-source copies (inference, untested).
