# 下一轮高层历史实验与 Harness VLA

建议先用现有 harness 做受控闭环试点，再在 Harness VLA 的官方实现 RPent 上做小规模适配复现。主问题是：同一动作能力与观测权限下，高层历史的组织和取用，怎样改变错误推进、重复和遗漏操作。

**完整设计保存于项目内：** [下一轮高层历史实验设计 v0.1](/Volumes/2T/Code/Others/LHC/experiments/high_level_history_next_round_v0_1.md)。其中包含任务起点、对照、预算、采样单位、决策门槛、接口改动及 RPent 复现协议。

## 任务与对照

| 任务 | 用途 |
|---|---|
| 取刀并确认稳固抓持 | 当前观察通常足够的能力/协议对照，已有物理成功记录 |
| 蘑菇处理与入碗进度 | 处理过哪些、转移是否完整、是否重复处理；复杂操作能力需先确认 |
| 相似配料盒身份保持 | 利用过去内容/放置记录找对奶酪容器；需补恢复入口和短技能能力资料 |

五组依次为：G0 近期记录、G1 通用递归摘要、G2 任务状态表、G3 状态表＋对象检索、G4 状态表＋判定条件检索。G3/G4 使用同样的模型调用次数、历史图像额度和文本上限，检验选择证据的方式。

先做三类任务各三个案例、五组，共 **45 条闭环续行**；若方向成立，扩展到每类十个独立历史前缀/初态，总量 **150 条**。同一官方轨迹的多个节点及重复 seed 按共同来源记录。任务执行不稳定时，把对应闭环问题转移到 RPent。

## RPent 复现

采用 LIBERO-10 的双物体入篮、碗入抽屉再关门、杯入微波炉再关门。三任务×五初态×直接 VLA/无参考记忆 harness/冻结参考记忆 harness 三组，计划 **45 条**。

论文原协议向规划器提供基准成功/终止信号。我们的评分保持在离线评估侧，并隔离不可见对象清单，因此使用“观测权限适配后的 RPent 对照”这一名称。三组的观察、原语权限和预算保持一致；评价期间不写回跨试次经验。
