工程上来说
**如何把任务依赖、动态世界状态和原始多模态证据统一起来，根据当前子目标选择、验证、重排和压缩历史，并通过机器人任务成败持续优化上下文构造**

从问题的角度出发
**在部分可观测、动态变化的长程机器人任务中，什么样的历史信息构成了当前决策的最小充分上下文，以及机器人如何在有限记忆和推理预算下学习、维护和获取这种上下文？**

#### 什么样的历史信息对未来决策是充分的
完整历史中包含大量信息，但只有一部分会改变：

- 当前世界状态估计；
- 可执行动作集合；
- 候选动作排序；
- 任务是否已经完成；
- 是否需要恢复或重新规划。

因此，历史事件是否重要，不应该由“它和当前问题语义上是否相似”决定，而应该由下面的问题决定：

**删除这个历史事件后，机器人的当前决策会不会改变？**

可以定义单个事件 e_i 的任务价值：

U(e_i\mid H_t,g_t) = V(H_t,g_t) - V(H_t\setminus e_i,g_t)

若删除某个事件导致：

- 选择了错误箱子；
- 重复执行已经完成的动作；
- 忘记某个码垛位已满；
- 再次使用此前失败的抓取位姿；
- 违反安全约束；

那么这个事件具有高上下文价值。
#### 长程轨迹应该按照什么边界切分
机器人轨迹可以按以下单位切分：

- 固定时间窗；
- 消息或模型 turn；
- Observation–Action–Result；
- 单个技能执行；
- 子目标；
- 世界状态突变；
- 成功或失败事件；
- 因果依赖链。
什么样的时间抽象单位，最能保留任务相关状态，同时最大限度降低历史复杂度？
**与固定窗口或 message/turn 切分相比，基于技能边界和状态转移的事件切分，在相同记忆预算下能够产生更低的决策失真**
#### 如何定义历史相关性
语义相关、时间相关、还是因果相关
```text
观测对象
→ 建立对象身份
→ 执行动作
→ 产生世界状态变化
→ 验证变化
→ 影响后续动作可行性
```
可以把某个历史事件定义为当前决策的因果相关事件，当且仅当：

对该事件进行删除、替换或干预，会改变以下至少一个量：

P(s_t\mid H_t)

A_{\text{feasible}}(s_t)

\arg\max_a Q(s_t,a)

即它改变了：

- 当前状态信念；
- 可行动作集合；
- 最优动作。

**任务条件化的因果依赖评分，在相同上下文预算下，比语义相似度、时间衰减和重要性评分更能保持动作决策一致性。**
#### 动态环境中的记忆何时失效
机器人记忆与文本 Agent 的根本区别是：过去正确的信息，在当前可能已经错误。
但更基础的科学问题是：

**如何估计一条记忆在当前时刻仍然有效的概率？**

可以表示为：

P(v_i^t=1 \mid e_i,\Delta t,o_{t-k:t},a_{i:t})

其中 v_i^t 表示历史事实 e_i 在时刻 t 是否仍有效。

这不应只由时间衰减决定，而应由：

- 对象类型；
- 可能发生的动作；
- 外部参与者；
- 环境动态性；
- 后续观测；
- 物理约束；

共同决定。

例如：

- “墙的位置”具有高持久性；
- “箱子当前位置”具有低持久性；
- “箱子已经完成质检”可能具有高任务持久性；
- “机械臂当前持有箱子”具有极短有效时间。

**基于状态持久性和后续动作的有效性估计，比固定时间衰减更能减少 stale-memory-induced errors。**
