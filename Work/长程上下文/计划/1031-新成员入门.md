## 二、项目一页纸

**研究问题**：长程具身任务里，上下文对规划决策值多少、价值从哪来、我们生成的记忆兑现了多少。兑现分三段：写下来、送到规划器、被用上。
- 这是 1027 改写后的说法。
- 1023 定的论文线是：上下文该留什么，怎样送到每次决策，什么时候该重新看、而不是相信记忆。

**系统**：
- **规划器**：一个能看图的大模型（现在用 deepseek-flash，温度 0，主实验不开思考），每一步选一个工具调用，比如转身、走向画面里的一点、环视、开、关、拿、放。
- **判断模块**：单独的一次模型调用，判断当前目标是否出现在画面里（G1/G2）。程序据此推进阶段，规划器不能自己结束任务。
- **四类记忆分开存**：
  - Task：程序维护；
  - Object、Spatial：各由一个模型从图像写记录；
  - Experience：v2 里关着。
  - 它们之间只共享原始证据。
- **上下文 v2**：1029 冻结，到目前为止的实验都用它。新的输出格式 v3 正在 THOR 上做在线对比。

**平台**：
- **BEHAVIOR-1K**：R1Pro，有真实的机器人本体，但慢，每次决策约 28 秒。
- **AI2-THOR**：快，每次决策约 8–10 秒；开、关、拿、放是语义化的工具，没有机器人本体。
- **RoboCasa365**：PandaOmron，有本体又快（约 8.5 秒）。1102 起是主平台（用户和导师讨论后定的），先把闭环跑通；BEHAVIOR 做验证。

**六条实验线**（详见进展页）：身体信息与卡住、规划器输出格式、感知兜底、多阶段记忆任务试点、RoboCasa 移植、BEHAVIOR 提速。

**到 1031 为止的状态**：
- **身体信息**：能让规划器换动作，浅的卡住更快脱困；目标在障碍后方时仍然卡住。开思考后，它明显更会往空地上绕；不开思考时，把生成的障碍、空地和路线送回去，作用有限。
- **输出格式**：离线两轮没看到改善；THOR 在线对比（原格式和新格式各 16 轮）正在跑。
- **感知**：专用 YOLO 的召回达标，空图误报和点位纠正没达标。THOR 的指物方式下一轮改成"点 + 名字"。
- **多阶段试点**：单纯找东西的阶段全部完成；要先搬东西的阶段大多失败，主要卡在点偏，还说明不了记忆的作用。

**还没定的大问题**：
- 推理在研究里占多大分量；
- 用哪种主口径；
- 需要"必要事实只在记忆里"的任务；
- 论文和投稿怎么安排（主平台 1102 定为 RoboCasa）。

## 三、规矩（必须遵守）

1. 四类记忆各自独立，只共享原始证据。要引入共享的语义存储，先讨论。
2. 仿真里的真实状态和计分，不进任何模型输入，只能在离线核对和计分时用。
3. 不动已有的运行、第三方仓库和共享的远程环境，包括开发机上 BEHAVIOR 的常驻进程和共享的 A100。
4. 源码、配置、文档进 Git；运行结果、权重和外部仓库不进 Git，版本记在运行清单里。
5. 行为有改动，才做针对性检查；纯数据或模板的改动不加测试。（仓库里的 `AGENTS.md`）
6. **研究流程**：
   - 顶层问题由用户先写，再请别人评；
   - 结果先给原始数据，再给解读；
   - 开跑前先写预测；
   - 每轮的范围定好后不再加项，新想法先记下来，写明什么时候再看。
7. 同样的输入、温度 0，两批之间回答也会变。所以每次都和同批对照交错着问，每个点重复多次。
8. 用中文，写得直白。

## 七、术语

| 词 | 意思 |
|---|---|
| G1 / G2 | G1：目标出现在当前任意一张头部图里，含环视图；G2：出现在正对方向的那张图里。G2 满足，这一阶段才算完成 |
| v2 / v3 | v2：1029 冻结的上下文和输出格式；v3：新的输出格式（先核对上一步、写依据和预期，再出动作），只在试点里用 |
| 三段兑现 | 写下来、送到规划器、被用上 |
| 起点 108 / 13 / 8 | BEHAVIOR 里的三个固定起点。108：目标在餐桌后面，会卡住；13：开局受阻；8：不会卡住 |
| B / T / G / TG | 三项离线检查的四组：原样、开思考、加绕行指引、两样都加 |
| P / N / V / R / VG | 生成事实送回的各组：受阻方向；加障碍和空地（生成时不知任务 / 知道任务）；再加路线；再加通用指引 |
| 宽口径 / 严格口径 | 宽：不朝受阻方向，原地转身也算；严格：移到地面、且偏开受阻方向 15° 以上 |
| 身体信息 | body_state（受阻的方向和距离）、failure_history（连续被挡的次数）、blocked_episode（这一段卡住的完整经过） |
| 读法线 | 开跑前定好的"算不算有效果"的门槛，只用来筛查 |
