## 先说结论

1. **位置**：站在第③类（记了也没用对）和第④类（测不清）的交界处，在规划器这一层，研究“记忆 → 判断 → 动作”这条链。
   - 不进第①类：给 VLA 加记忆最拥挤，而且要训练模型。
   - 不走第⑤类的预训练路线：那是公司在做的事。
2. **三篇论文，都挂在总故事下**：

   | 论文 | 回答什么 | 类型 |
   |---|---|---|
   | A | 信息出错有多严重、从哪来：一个错误事实怎样同时带偏下一步动作和完成判断 | 测量 |
   | B | 预算有限时，什么时候信记忆、什么时候去检索、什么时候重新去看、什么时候先核实再推进 | 方法 |
   | C | 算力和延迟也是预算：上下文越积越长时，怎样控制记忆和判断调用的成本 | 系统 |

3. **A 现在就能开始**：离线干预只需要 API 和已存的记录，不必等工具链。

## 一、为什么站这个位置

| 类别 | 拥挤程度 | 和我们条件的匹配 |
|---|---|---|
| ① 给 VLA 加历史 | 最挤：29 篇，2026 年 6 月一个月约 10 篇 | 差：要训练模型，你几乎没有训练经验，算力只有一张 5090 |

## 二、三篇论文

### 论文 A：错误事实怎样同时带偏动作和完成判断（测量）

- **问题**：沿用 1016 的定稿。规划器、记忆写入和完成判断共用一份记忆时，一个错误事实会不会在同一个决策点上，同时带偏下一步动作和完成判断？错误是从哪一环进来的？
- **平台**：BEHAVIOR 找刀任务，加上 10-19 设计里的三个操作任务。
- **核心实验**：就是 1020 的 D1–D4。
  - 先标注决策点，并按信息空窗分档；
  - 再做三种离线干预：去掉或替换规划器的叙述、改对或注入一条事实、换取证方式；
  - 加上 20+20 轮在线配对。
- **主要结论的形式**：把错误分解为感知错误（空窗为 0）、写入遗漏、叙述带偏三种来源，并给出各自传到动作和完成判断两边的比例。
- **和已有工作的差异**：
  - CMA 审计的是 VLA 的历史，只看动作；
  - Present but Not Remembered 看的是表示有没有编码历史；
  - MobiAgent 只定性记录过一个例子。
  - 我们在规划器层，把动作和完成判断成对测量，并做因果干预。
- **成本**：
  - API 调用：1020 笔记估计每组离线干预约 1,100 万输入 token；
  - 论文需要第二个模型复现，在 5090 上跑 7–8B 的开源视觉语言模型。
- **副产品**：一份决策层记忆审计数据，含成对标签和信息空窗，可以随论文发布。
- **目标**：
  - 首选 IJCAI 2027（往年 1 月中旬截稿）；赶不上就投 NeurIPS 2027（往年 5 月）；
  - 退路是 T-ASE 期刊。
  - 截稿时间都按往年惯例估计，以官网为准。
- **退路**：共同错误很少时，按 1016 的退路，转为研究单边损害，以及补证的成本收益。

### 论文 B：预算下的信息操作调度（方法）

- **问题**：记忆容量、检索成本、重新观察成本都有限时，智能体怎样决定下一步是信记忆直接做、去检索、重新去看，还是先核实再推进？最优的执行顺序会不会因此改变？
- **平台**：
  - grouped-assembly 玩具环境：一轮几秒，用来得到干净的结论；
  - BEHAVIOR 离线回放：复用 A 的决策点，用来证明结论在真实场景里成立。
- **要先补的东西**：
  - 玩具环境加上“看证据再行动”的候选策略，对应四种思路：信息够了就停、不确定才重看、意外才记、核实后才推进；
  - 用 DSSR 的拆法分析结果：总损失 = 预算损失 + 写入遗憾。
- **和已有工作的差异**：
  - MemCompiler、MemPrism、STaR、SimpleARM 决定取什么，默认检索不花钱，也默认记忆内容是对的；
  - Mind Palace、UQ-DAAAM、InfoSeeker 决定什么时候收集信息，但服务的是答题或规划；
  - 我们把重新观察当作记忆的替代品，和物理动作放进同一个预算里一起安排，并用 A 的完成判断错误来评价。
  - 这一条只核对过摘要，要精读后再写定。
- **目标**：AAAI 2028（往年 8 月截稿）或 ICRA 2028（往年 9 月截稿）。

### 论文 C：上下文的时延和算力成本（系统）

- **问题**：一轮任务里，记忆和判断调用的上下文越积越长，尾部延迟会怎么变？怎样在给定的延迟目标下，分配上下文预算和模型调用？
- **平台**：
  - 5090 上的本地视觉语言模型，同时兼作论文 A 的第二个模型；
  - A 的在线轮次。
- **和已有工作的差异**：BRACE 只管重规划调用；我们把记忆写入、完成判断和取证调用一起调度。
- **目标**：MLSys（在你们学校的认可列表上）或 T-ASE。

## 四、主要风险

1. **工具链拖慢进度。** 应对：严格冻结；起点分档；必要时用“理想导航”条件，把“去哪”和“怎么走”拆开。
2. **自然错误太少。** 应对：用 D3 的反向注入和“必须靠记忆”的任务变体，主动制造需要记忆的决策点；同时保留单边损害这条退路。
3. **方向被抢先。** 第③④类正在快速出论文（SimpleARM 9 月底，CMA 9 月底）。应对：每月查一次 arXiv，关键词是 memory audit、progress verification、embodied judge bias。
4. **只用一个模型。** 应对：论文 C 的本地模型兼作复现。
5. **会议认可。** IROS 是 CCF-C，CoRL、RSS、RA-L 不在列表上，都不能当毕业论文的主投目标。
