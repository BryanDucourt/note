## 二、我们的问题（读之前先了解）

- **场景**：长程具身任务（BEHAVIOR 这一类）。我们手上的示范 episode 有 15,663 帧、67 个技能段。系统里有多个使用历史信息的模块，下文统称“消费者”：VLM 规划器、VLA 或技能执行器、执行监控（判断这一步成没成）、任务评估（判断整个任务完成没有）。
- **导师的方向**：完整记忆统一存一份，再为不同消费者生成不同的表征或压缩。
- **目前的问题表述**（见 [1015-讨论-结论](1015-讨论-结论.md)）：在上下文预算受限时，研究历史表示怎样同时保住规划能力和完成判定能力。具体两个问题：
  1. 共享表示里的遗漏、失真、过时，什么时候会让规划和验证在同一个事实或目标上一起出错？
  2. 按当前判定的需要重新取证，和同预算下的“重新生成一份共享摘要”“状态表＋检索”相比，能减少多少共同错误，代价是什么？
- **第三节第 7 部分要对照的四点**：
  1. **双目标压缩**：表示是否同时服务规划和完成判定？两者是否分别评估？
  2. **错误连带**：共享表示出错时，规划和验证会不会一起出错？有没有测量？
  3. **按判定取证**：压缩或检索是否以当前这次判定需要的信息为条件？有没有在同预算下和“通用共享摘要”“状态表＋检索”比较？
  4. **自然错误率**：有没有在未注入错误的轨迹上，统计表示写错、错误被下游采纳、最终造成损失的比例？

## 三、每篇要交付的内容

每篇控制在 1,500 字左右，表格不计。按下面的顺序写。

### 1. 基本信息
出处、版本、发表情况、主要团队、代码是否公开。

### 2. 一句话和要解决的问题
一句话说清楚这篇做了什么；再写它针对的具体问题，以及作者认为已有方法哪里不行。

### 3. 方法：按下表逐项回答

这一节是重点。每项都要写到具体机制，并标出处（章节、公式、表格或页码）。论文没写的项写“论文未说明”。

| 维度 | 要回答的问题 |
| --- | --- |
| 历史规模 | 任务多长（步数、时长、子任务数）？压缩前后的上下文各多大、压缩比多少？数字写明口径（步、帧、秒、token）。 |
| 存储来源 | 存的是当前任务的历史，还是过去任务的经验？存原始数据还是加工后的？ |
| 表示形式 | 文本、视觉 token、latent，还是结构化记录？是否混合？不同部分分别交给谁？ |
| 消费者 | 有几个？同构还是异构（模态、频率、接口不同）？各自看到什么？ |
| 压缩条件 | 以什么为条件：目标、偏好、查询、规划意图，还是无条件？什么时候生成：每一步、事件触发，还是按需？ |
| 训练信号 | 有没有学习？用什么监督（动作损失、未来轨迹、人工标注、LLM 生成的标签）？是否用到推理时拿不到的信息？消费者是否冻结？ |
| 更新与一致性 | 新证据到来时怎么更新？旧内容会不会失效？有没有“已过时”或“推测”的标记？ |
| 完成判定 | 表示是否承担进度或完成判断？由谁判断？判断依据是否独立于规划器的输出？ |
| 共享 vs 分开 | 有没有在同一预算下，和“通用共享摘要”或“状态表＋检索”这类基线比较？ |
| 错误分析 | 有没有统计记忆或表示本身的错误？有没有注入实验？错误怎样影响下游？ |
| 成本 | 总 token、延迟、调用次数、存储分别是多少？按什么口径算？压缩本身的开销算进去了吗？ |

### 4. 实验
- 数据集与任务；
- 基线是作者自己实现的还是官方的；
- 每组的试验次数或样本量，有没有方差；
- 评测点是否专门挑了依赖历史的场景，这类场景占多大比例；
- 关键数字（附出处）；
- 消融做了什么、没做什么。

### 5. 结论站不站得住

| 结论 | 证据强度 | 依据 |
| --- | --- | --- |

证据强度分三档：**支持**＝有直接的实验或证明；**弱**＝有证据，但样本少、缺对照或有混杂；**无**＝基本没有证据。

### 6. 代码与补充材料
初筛时没在四篇的 PDF 里找到代码链接（MEM 只有项目页）。精读时请再确认：
- 有公开代码的，抽查方法里最关键的两三处实现，写明 commit 和文件位置；
- 没有的写“无公开代码”；
- 附录或补充材料缺失的也要写明。例如 MeMento 的 PDF 只有 10 页，正文多处写“见附录 ??”，附录可能不在这个版本里。

### 7. 对我们的影响
- **覆盖了什么**：对照第二部分的四点，逐条判断“已覆盖 / 部分覆盖 / 未覆盖”，并说明依据。
- **留下了什么**：有哪些空白是我们可以做的？
- **能借用什么**：方法组件、实验设计、评测指标、数据或代码。
- **如果当基线**：怎么接到我们的设定里（同样的当前观察、原始记录访问权和总预算）？需要改什么？
- **导师可能会问的问题**：两三个。

## 五、规则

- **出处**：每个事实性说法都标出处（章节、公式、表格或页码）。数字必须来自原文，不要四舍五入后再转述。
- **事实和推断分开**：论文明确写了的直接陈述；属于你自己判断的，句首标“【推断】”。
- **不要只读摘要和引言**：方法、实验和附录都要看，特别是附录里的实验设置和补充实验。
- **判断“已覆盖”要逐项对照**：要按第三节第 3 部分的维度逐项对照我们的设定，不要因为用词相近就判定为已覆盖。
- **不确定就写“未核实”**，不要补全或猜测。
- **只读这四篇**：不扩展到其他论文；引用其他工作时只写论文里怎么说的。第四节第 3 条可以引用 1015 的笔记。
- **格式**：中文 Markdown，标题层级和 1015 的精读一致。
