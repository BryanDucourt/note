# 具身智能"上下文系统"研究议程：问题、增量改进与新方向（截至 2026 年 10 月）

**结论先行：**到 2026 年，"给 VLA/具身 agent 加上记忆"本身已经没有新意。真正还没解决的是三件事，也是我们最值得投入的地方：**记什么、何时忘（写策略）**，**按什么键取（读策略）**，以及**取出来的记忆是否真的在指导动作（可归因评测）**。最快能出成果的路线有两条：一是把 MEM 的语言记忆与 3D/物体级记忆统一成一个结构化记忆；二是把 Zeva 的 PIM 做成跨 episode 的终身记忆，并配上学习型检索与巩固机制。最有原创空间的方向则是"可审计、可反事实检验的记忆"，以及"面向物体的持久世界状态记忆"，后者可以把高层（3DLLM-Mem）和低层（MEM/Zeva）打通。

## TL;DR

- **领域现状：**2025–2026 年涌现了几十个记忆型 VLA/WAM，例如 MemoryVLA、MemER、MEM、MemoryWAM、DiM-WAM、RoboTTT，以及 RoboMME、RMBench、MIKASA-Robo-VLA 等基准。共识已经形成：一是朴素地拼接长历史会因为训练–推理分布偏移而失败；二是"稀疏关键帧或事件"加"分层/多尺度"表示有效；三是最优的记忆表示依赖任务，在 RoboMME 上感知记忆优于符号记忆，符号记忆又优于循环记忆。
- **最薄弱的环节：**几乎所有方法的记忆都局限在单个 episode 内，没有删除、遗忘或过期处理（MemER、3DLLM-Mem、MEM、Zeva 都承认这一点）。检索大多靠启发式（相似度或阶段）。至于记忆是否真的在指导动作，2026 年的反事实审计工作表明：记忆改变了动作，并不等于记忆引导了动作。
- **建议的投入顺序：**(1) 先建一套"表示 vs 检索 vs 使用"可分离的诊断评测协议，这是低成本、高引用潜力的基础设施；(2) 在 openpi π0.5 上做增量工作：结构化混合记忆，加上学习型检索，加上带遗忘的写策略；(3) 押注一个新方向：面向物体的持久记忆和跨 episode 的终身上下文，用自监督（预测未来/过去、动作效果）取代 LLM 标注。

## 一、现有工作定位与局限

### 1.1 三篇起点论文

|论文|定位|核心机制|关键局限（论文自述或可推断）|
|---|---|---|---|
|**MEM**（Physical Intelligence, arXiv 2603.03596）|真机低层 VLA，多尺度记忆|短期：视频编码器做时空可分离注意力（不增加参数）；长期：高层策略递推更新自然语言摘要 m_t→m_{t+1}，摘要的监督来自 LLM 根据子任务标注生成|支持长达 15 分钟的任务，但作者明确把"跨 episode、持续数周到数年的记忆"列为未来工作；语言摘要会丢失细粒度空间信息；摘要质量受[1][2] LLM 标签上限约束|
|**Zeva**（清华 AIR, arXiv 2608.30880）|真机低层，冻结策略做"上下文因果学习"（ICCL）|CTE（GRU 编码 [视觉潜变量, 动作, 状态差]），输出相位 token 与因果交互信号；BIT（尝试内滑窗）与 PIM（跨尝试合并）两级记忆；按相位做 top-K 检索；causal prompt 注入扩散动作通路[3][4]|PIM 只在同一 episode 内跨尝试使用（官方 README 原文写的是"across attempts in the same episode"）；检索键是启发式的相位相似度；只从任务尝试中学习，不做主动探索；评测规模小[3]|
|**3DLLM-Mem**（UCLA/Google, NeurIPS 2025, arXiv 2505.22657）|仿真高层规划/导航|工作记忆 token 作为 query，对稠密 3D 特征的情景记忆库做 cross-attention 融合；3DMem-Bench（超过 26,000 条轨迹、2,892 个具身任务）[5][6]|只有高层动作；所有时间步都参与全量融合，扩展性差；后续工作批评其"未剪枝的记忆会累积冗余条目、长视频计算成本高"；没有遗忘或巩固；环境变化及对应观测是预先采集并存储在本地的（论文 §3.2）|

3DLLM-Mem 的成绩值得记住：在最难的 in-the-wild 任务上比最强基线高 16.5% 成功率，in-the-wild 平均成功率 32.1%；在 hard in-the-wild 任务上为 27.8%，而 Most Recent Memory 仅 5.4%、Retrieval-Augmented Memory 仅 4.8%（论文 Table 2a，原文称其他方法"achieving only ~5% success rate in hard in-the-wild tasks"）。这说明在高层，显式的时空记忆收益很大，但绝对成功率仍然偏低。

Zeva 的后续工作 **Zeva-Ego**（arXiv 2609.24411）补上了"用第一人称人类视频做 mid-training"，部署时仍完全依靠演化的上下文而不更新权重。但跨[7][8] episode 持久化这一缺口依然存在。

### 1.2 2024–2026 关键相关工作（已核实）

**A. VLA 侧的记忆（低层控制）**

- **MemoryVLA**（arXiv 2508.19236，ICLR 2026）：工作记忆由感知 token 和认知 token 组成，作为 query 从感知-认知记忆库（PCMB）中检索，经门控融合；当条目超过容量 L 时，合并余弦相似度最高的相邻条目来做巩固。评测覆盖[9] 3 种机器人上的 150 多个任务、500 多种变体，12 个真机任务平均成功率 84.0%；在 6 个真机长时依赖任务上达到 83%，而 CogACT 为 57%、π0 为 52%。后续的 MemoryVLA++（arXiv 2606.09827）加入了"想象"模块（未来潜变量）。也有批评指出它的递归融合会造成信息衰减（见[10] Keyframe Chaining，arXiv 2603.01465）。[11]
- **MemER**（arXiv 2510.20328，ICLR 2026，Stanford/Finn 组）：分层结构，高层用微调后的 Qwen2.5-VL-7B 提名关键帧并输出子任务语言，低层用 π0.5。每个任务只用[12][13] 50 条遥操作示范。在线巩固做法是把候选关键帧聚类后取中位帧。三个重要发现：①纯视觉记忆比文本记忆更鲁棒，文本记忆会过度依赖规范的子任务顺序，在协变量偏移下很脆弱；②据论文[14][15] §4.1（每方法每任务 20 次试验），32 帧（约 16 秒）长历史基线推理一次需约 1 秒，平均成功率仍比 MemER 低 34%；③作者在 §5 明确承认目前只会持续累积关键帧，"缺少在关键帧过多时丢弃它们的机制"，并把学会删除列为未来工作。
- **BPP**（arXiv 2602.15010）：用现成的 VLM 通过简单问答（例如"抽屉是否刚被打开？"）检测关键帧，策略只以关键帧为条件。核心论断是：历史条件策略失败的主因不是架构容量，而是训练数据对指数级历史空间的覆盖不足。真机成功率比最佳对照高 70%。VLM 延迟 3–5 秒，训练时用 latency-masking 应对。[16][17][18][19]
- **Past-Token Prediction（PTP）**（Torne et al., CoRL 2025, arXiv 2505.09561）：辅助任务是同时预测过去和未来的动作 token，并可在测试时用于自我验证；在 4 个真机任务上，无历史基线平均成功率仅 15%，PTP 达到 70%（Tape Replacement 任务上 PTP 为 80%，两条基线均为 0），训练加速 10 倍以上。需要注意，一篇 2026 年的复现工作（arXiv 2606.16447）发现，冻结观测编码器本身就贡献了很大一部分增益，PTP 并非在所有任务上都有效。[20]
- **RoboTTT**（NVIDIA/Stanford/UT Austin, arXiv 2607.15275）：用 TTT 的快速权重作为循环状态，上下文扩展到 8K 时间步，而推理延迟不随之增长。结果：单段人类视频 one-shot 模仿 10 次成功 6 次，基线全部失败；扰动下成功率 83%，最佳短上下文基线为 53%；相对单步上下文提升 87%。8K 上下文预训练相对 1K 的增益，摘要写 62%，正文写 63%，原文前后不一。这是"把记忆写进参数"路线最强的证据。
- **RoboMME**（arXiv 2603.04639，ICML 2026 Oral）：16 个任务，覆盖时间、空间、物体、程序四类记忆；基于 π0.5 构建了 14 个记忆变体，表示分为感知、符号、循环三类，注入方式分为 context、modulator、expert 三类。总体排序是感知记忆优于符号记忆、符号记忆又优于循环记忆，但"效果高度依赖任务"。[21][22]
- **RoboMME-Interference**（arXiv 2606.22338）：在历史中加入不相关的会话后，感知记忆变体的表现"随干扰累积强烈而稳定地衰减"；只要加一个按视觉相似度检索的步骤，就能在所有干扰水平下恢复到无干扰时的成功率。**这直接说明检索是跨会话记忆的瓶颈**。[23][24]
- **反事实审计**（arXiv 2609.27247，"Memory That Changes Action Is Not Memory That Guides It"）：构造两段任务一致、但当前输入相同的历史，审计 Mem-0 与 BridgeVLA++。在 Swap 决策上，24 对历史全部改变了动作，但选中的分支从未改变（正确率 0.5，可靠对数 0/24）；把记忆替换成指向相反目标的历史后，成功率降到 0/48。**这是"记忆是否真的被用于决策"最有力的反例证据。**[25]
- 另有一篇第三方审计（"Present but Not Remembered"，arXiv 2607.03372）报告：CronusVLA 的历史在干净输入上只贡献约 +0.050，打乱帧序后贡献约为 0，说明模型没有利用时序。本次未能独立核实该论文全文，作为待验证线索。[26]
- **μVLA**（arXiv 2606.12497）：在 MIKASA-Robo 上，"有记忆减无记忆"的差距在 chunk=1 时最大，长 action chunk 的推理会部分绕过循环通道。**动作分块与记忆之间存在耦合**，这一点常被忽视。[27]
- **其他**：SAM2Act / SAM2Act+（arXiv 2501.18564，ICML 2025）在 MemoryBench 上平均 94.3%，比无记忆版本高 39.3 个点，但 MemoryBench 只有 3 个空间记忆任务，可复现性也受到 RMBench 质疑；ContextVLA（arXiv[28][29] 2510.04246）把多帧压缩成摊销的上下文 token；CycleManip（arXiv[30] 2512.01022，CVPR 2026）面向计数型循环任务，用代价感知的历史采样加进度预测；KEMO（arXiv[31][32] 2606.23589）做事件驱动的关键帧记忆，相对无记忆基线 TSR 提升 23.6%；AEM（arXiv 2606.12499）把视觉-动作交错历史做掩码重建预训练，把"动作-效果"压缩进末端 token。[33][34][35]

**B. 世界动作模型（WAM）中的记忆**

- **MemoryWAM**（arXiv 2606.20562）：混合记忆由三部分组成：最近帧的滑窗、事件边界锚帧、压缩的 gist token。在 RMBench 上达到 83.0%，提升 4.8 个百分点，延迟和显存都低于全注意力、TTT、RNN 方案。[36][37][38][39]
- **DiM-WAM**（arXiv 2606.27677）：8 个记忆库、每个 12 个槽位，加任务进度监督。RMBench 平均成功率从 LingBot-VA 的 28.4% 提到 69.8%，显式记忆基线 Mem-0 为 42.0%。注意数字口径不一致：项目页的"训练匹配对比"写的是[40][41] 34.8%→69.8%；真机全任务成功率，摘要写 52.5%→80.0%，正文表格写 90.0%。引用时需要注明口径。[42][43][44]
- **WAM-TTT**（arXiv 2607.06988）：部署时只用无标注的人类视频，通过自监督视频预测更新冻结 WAM 内视频侧 TTT 层的快速权重，相当于"把人类视频吸收进一块轻量自适应记忆"。[45][46]
- **MaP-WAM**（arXiv 2609.11561）"记忆即计划"：长期稀疏视觉上下文只在规划时使用，执行器的上下文长度固定。**Mem-World**（arXiv[47][48] 2606.18960）在世界模型中使用以腕部视角为中心、按 surfel 索引的 4D 记忆，做几何感知的检索。**WorldMem**（arXiv[49] 2504.12369）用带位姿和时间戳的帧记忆库来提升视频世界模型的长期一致性。[50]

**C. In-context learning 型基础模型（工业界）**

- **GEN-1.5**（Generalist AI，2026 年 8 月）：30 秒上下文，以 100 Hz 输出动作；一次 3–12 秒的示范放进上下文后，10 个任务的平均 one-shot 成功率为 59%，做 1–10 步梯度更新后升到 83%。公司称没有专门为 ICL 做架构改动、元学习或辅助目标，ICL 能力是从规模化物理预训练中涌现的。[51][52][53]
- **Skild S1**（2026 年 8 月 18 日）：自称首个在"预训练中未见过的、长达 10 分钟的长时任务"上展示 ICL 的机器人基础模型；称一段上下文视频约等于 380 条后训练示范，但这个数是插值估计。这些都是公司博客或媒体报道，没有同行评审，也没有开放权重。[54][55]
- **π*0.6 / RECAP**（arXiv 2511.14759）：属于"从经验中学习"，但走的是参数路线，即优势条件化的离线 RL，不是上下文记忆。它是跨[56][57] episode 经验积累的重要参照：经验写进权重，而不是写进上下文。

**D. 高层 agent 记忆、空间记忆与 3D 场景记忆**

- **MemCompiler**（arXiv 2605.07594，与 Zeva 同属 AIR embodied-brain 团队）：命名了 AMMI（在 episode 开始时一次性静态注入检索记忆）这一范式，并指出它会让轻量执行器的表现跌到无记忆基线以下。改为按当前执行状态（Brief State）逐步"编译"记忆后，在 ALFWorld、EmbodiedBench、ScienceWorld 上最高提升 129%，单步延迟降低 60%。[58][59]
- **EmbodiSkill**（arXiv 2605.10332）：免训练，区分"技能本身错误"与"执行疏漏"并据此修订技能；在 ALFWorld 上让冻结的 Qwen3.5-27B 达到 93.28%，比最强的记忆基线 G-Memory 高 25.01%。说明**程序性/技能记忆比轨迹级检索更有效**。[60][61]
- **KARMA**（arXiv 2409.14908）：长期记忆用 3D 场景图，短期记忆记录物体状态变化。消融显示短期记忆主要决定成功率，长期记忆主要决定效率。[62][63]
- **ReMEmbR**（NVIDIA, arXiv 2409.13682）：把 VLM 字幕连同位置、时间戳存入向量库，由 LLM 检索；后续工作批评重复访问时纯字幕记忆冗余。**MemoryEQA**（arXiv[64][65][66] 2505.13948）在 MT-HM3D 上比基线高 18.9%，但 2026 年的后续工作（arXiv 2607.21571）发现，在顺序 EQA 中记忆收益不到 3%，原因是条目堆积、检索变噪。[67][68]
- **Cambrian-S**（arXiv 2511.04670）：用自监督的下一潜帧预测误差（surprise）驱动记忆压缩和事件分割；VSI-590K 训练让 VSI-Bench 绝对提升 30%。但 "Solving Spatial Supersensing Without Spatial Supersensing"（arXiv 2511.16655）证明：只用 SigLIP 逐帧处理就能近乎解决 VSR；房间重复 5 次后，Cambrian-S 在 VSC 上从 42% 崩到 0%。**基准捷径是空间记忆评测的头号风险。**[69][70]
- 以下工作本轮**未能逐篇核实**，引用前请自行确认：ConceptGraphs、HOV-SG、3D-Mem（snapshot 记忆）、Embodied-RAG、OpenEQA、TraceVLA、Thinking in Space / VSI-Bench、Spatial-MLLM、VLM-3R。其中 3D-Mem 已作为 3DLLM-Mem 的基线出现，其存在可以间接确认。

**E. 基准**

RMBench（arXiv 2603.01229，9 个双臂任务，按"任务记忆复杂度"M(1)/M(n) 分级，并提供 Mem-0 策略）；RoboMME（16 个任务）；MIKASA-Robo（32 个任务）与[22][28] MIKASA-Robo-VLA（arXiv 2610.00604，90 个语言条件任务、22,500 条 oracle 轨迹，无记忆的 π0.5 仅 0.211）；RoboCerebra（NeurIPS 2025 D&B，1,000 条轨迹、100 个任务变体，面向 System-2）；3DMem-Bench；MEMOBench（arXiv[27][71][72][73] 2609.07047，过程级记忆）；EmbodiedMemory-Bench（arXiv 2609.28236）；RoboMemArena（arXiv 2605.10921）。

## 三、核心研究问题

下表列出一个具身上下文系统必须回答的问题。"现状"一栏给出现有工作回答得如何。

|#|研究问题|现状|证据|
|---|---|---|---|
|Q1|**哪些信息与决策相关，粒度多细？**（计数、遮挡物位置、失败原因、接触参数）|部分回答，答案依赖任务|RoboMME 显示表示优劣依赖任务；MaP-WAM 指出语言记忆丢失细粒度视觉证据|
|Q2|**怎样做到既紧凑、又能直接驱动低层控制？**|有多种方案，但缺统一理论|MEM 用视频加语言，MemoryWAM 用锚帧加 gist，RoboTTT 用快速权重|
|Q3|**写什么、何时写、何时忘？**|**回答很差**|MemER 自述缺少在关键帧过多时丢弃它们的机制；3DLLM-Mem 被批冗余累积；MemoryEQA 后续工作发现条目堆积导致收益不到 3%|
|Q4|**具身场景下检索键该怎么定义？**（时间、空间、因果、阶段、任务）|**回答很差**，全是启发式|Zeva 用相位相似度，RoboMME-Interference 用视觉相似度，二者都是手工设计|
|Q5|**环境非平稳、记忆过期怎么办？**（物体被他人移动）|**基本空白**|3DLLM-Mem 论文 §3.2 明言环境变化及对应观测是"预先采集并存储在本地"的；没有低层工作处理这一问题|
|Q6|**没有标签时如何监督记忆？**|有萌芽|MEM 依赖 LLM 标签；AEM、PTP、Cambrian-S、WAM-TTT 提供了自监督思路|
|Q7|**训练–推理分布偏移与因果混淆**|被反复确认，解法零散|BPP（覆盖不足）、MemER（文本记忆在偏移下脆弱）、MEM（朴素子任务历史失败）、PTP|
|Q8|**记忆是否真的在指导动作？**|**刚开始被追问**|反事实审计：动作被改变但分支选择不变（0/24 可靠）[25]|
|Q9|**如何跨 episode、任务、本体迁移？**|很弱|Zeva 有初步的跨任务信号迁移；GEN-1.5 与 S1 有 ICL，但闭源|
|Q10|**如何评测并隔离记忆的贡献？**|基准多，诊断少|Cambrian-S 被捷径攻破；RMBench 质疑 MemoryBench 的可复现性|
|Q11|**记忆与 action chunk、延迟之间的耦合**|很少被研究|μVLA：长 chunk 会绕过记忆；BPP 需要 latency-masking|

**高层与低层之间的断层：**3DLLM-Mem 一类工作有空间结构，但不输出连续控制；MEM、Zeva 一类有连续控制，但记忆是"时间线性"的（语言摘要、相位序列），没有"某个物体在哪、状态如何"这种可查询的世界状态。两类工作之间缺一个**以物体为中心、可同时被规划器和动作专家读取的持久表示**。MemER 的作者也在 §5 明确写道，扩展到移动操作和多房间任务时，"记忆必须把空间建图与情景回忆交织起来"（"memory must interleave spatial mapping with episodic recall"）。

## 四、增量改进方向（基于 MEM / Zeva / 3DLLM-Mem，可用微调完成）

### A1. MEM 语言记忆与空间/物体槽位的混合记忆（"Grounded MEM"）

- **研究问题：**纯语言长期记忆在空间任务上丢失细节（MaP-WAM、MEM 自述），纯视觉记忆又缺乏抽象。加入接地的物体槽位（语言描述 + 图像坐标/3D 位置 + 最后观测关键帧）能否同时拿到两者的好处？
- **为何仍开放：**RoboMME 的 GroundSG（带图像坐标的子目标）只是一个单点尝试；MemER 发现文本记忆在协变量偏移下脆弱。[14][74]
- **方法草图：**在 openpi 的 π0.5 上复刻 MEM 式的语言摘要头（标签可由开源 VLM 依据子任务注释生成），再加一组 K 个物体槽位，每个槽位包含文本、2D/3D 坐标和关键帧 token，通过一个小 cross-attention 专家注入。训练沿用 MEM 的经验：在预训练或中期训练阶段就引入记忆，而不只在后训练阶段。
- **基准：**RoboMME（空间与物体子集）、MIKASA-Robo-VLA、RMBench。
- **难度/风险：**中等。风险在于槽位与真实物体的对应（数据关联）出错。资源：8×A100/H100 级别，π0.5 LoRA 或全参数微调约 1–2 周。

### A2. 把 Zeva 的 PIM 做成跨 episode 的终身记忆，并加入巩固与遗忘

- **研究问题：**Zeva 的 PIM 在 episode 之间被清空。跨 episode 保留同一任务或同一物体的"动作-效果"证据，能否带来持续改进而不发生干扰？
- **为何仍开放：**RoboMME-Interference 表明，不相关会话一累积，感知记忆就强烈衰减；但它同时表明检索能恢复性能，所以"跨[23] episode 的效果取决于检索质量"是一个可检验的假设。
- **方法草图：**PIM 条目加上元数据（任务嵌入、物体身份、环境指纹、时间戳、结果）。巩固阶段对高频且结果一致的条目做原型合并（类似 MemoryVLA 的相邻合并，但按语义聚类），遗忘阶段按"使用频率 × 结果价值 × 时间衰减"打分淘汰。检索时先按任务/环境过滤，再按相位排序。可以直接复用 Zeva 开源代码里的 CTE、BIT/PIM 模块。
- **基准：**RoboMME-Interference 的跨会话协议（最直接）；LIBERO/RoboCasa 中同一任务多次部署的设置；RoboTwin。
- **难度/风险：**中低。主要风险是 Zeva 的评测规模小，基线本身的可复现性需要先验证。资源：冻结策略加小模块训练，单机 4–8 卡即可。

### A3. 学习型检索取代相位相似度和视觉相似度

- **研究问题：**检索键能否从"下游动作损失或成功率"中端到端学出来，而不靠手工设定的相位或余弦相似度？
- **为何仍开放：**Zeva 用相位 top-K；RoboMME-Interference 用视觉相似度；MemCompiler 证明"按状态编译"比静态注入好，但它是 LLM 文本层面的方法。低层 VLA 里还没有学习型检索。
- **方法草图：**两阶段。①检索器给每条记忆打分，用 Gumbel-top-K 或 straight-through 估计，以动作流匹配损失反传；②用"留一条记忆"的反事实增益（去掉这条记忆后动作损失的变化）作为检索器的蒸馏目标。检索键由当前视觉、相位、进度、物体槽位拼接而成。
- **基准：**RoboMME、RMBench M(n) 任务、加干扰的 MIKASA-Robo-VLA。
- **难度/风险：**中等。离散选择的梯度方差大，反事实标签的计算成本高，可以离线预计算。

### A4. 用结果信号或 RL 训练写策略

- **研究问题：**"写不写、写什么"能否用任务结果或优势函数监督，而不靠 LLM 生成的摘要标签（MEM）或 VLM 问答（BPP）？
- **方法草图：**把写操作建模为 MDP 中的离散动作，奖励等于任务成功减去记忆容量惩罚，在仿真中用 PPO/GRPO 训练一个小写入头，基础策略冻结。也可以借鉴 π*0.6 RECAP 的优势条件化，对"写入后优势提升"的样本加权。
- **基准：**MIKASA-Robo（专门为 RL 设计，pip 可安装）、RMBench。[75]
- **难度/风险：**中高。存在信用分配难题；建议先从 MIKASA 的短任务做起。

### A5. 为 3DLLM-Mem 加入过期处理与可扩展检索

- **研究问题：**环境被他人改变后，旧的 3D 记忆会误导规划。能否检测记忆与当前观测之间的冲突并更新？能否用分区或空间索引的 top-K 取代对全部时间步的 cross-attention？
- **方法草图：**记忆按空间体素或房间分区，并记录"最后验证时间"；当前观测与记忆特征的一致性得分低于阈值时，标记过期并降权或替换。检索改为"空间邻域 + 语义 top-K"两级。训练数据可以在 3DMem-Bench 的 HM3D 场景里程序化生成"物体被移动"的变体。
- **基准：**3DMem-Bench（加扰动变体）、HM3D/Habitat、OpenEQA（使用前请核实版本与许可）。
- **难度/风险：**低到中。LLaVA-3D 的微调成本可控。这是最适合"快速发第一篇"的方向。

### A6. 动作分块感知的记忆读取

- **研究问题：**μVLA 显示长 chunk 会绕过记忆。能否让记忆在 chunk 内部重新读取，或让记忆决定 chunk 长度？
- **方法草图：**在 π0.5 的流匹配去噪过程中，每 k 步刷新一次记忆 query；或训练一个"记忆不确定性"头，在需要回忆时动态缩短 chunk。
- **难度：**低到中。实验便宜，结论清晰。

## 五、新方向

### B1. 可审计的记忆：反事实忠实度作为训练目标，而不只是评测指标 ★推荐

- **研究问题：**能否训练出"记忆不同，则决策分支随之正确改变"的策略？
- **为何仍开放：**反事实审计表明，现有记忆策略在关键决策上"动作被改变、分支不变"（Swap 任务 0/24 可靠）；"Present but Not Remembered"报告 CronusVLA 对帧序不敏感（待核实）；Cambrian-S[25][26] 被捷径攻破。
- **方法草图：**①仿照审计协议，在仿真里程序化生成"当前观测相同、历史不同、最优动作不同"的成对数据（RoboMME、MIKASA 的任务生成器都支持）；②训练时加入对比式反事实损失：交换记忆后，动作分布应向另一分支移动；③配合 PTP 式的过去预测作为正则。
- **产出：**一个基准（反事实成对集）、一个训练方法、一套诊断指标（敏感度、选择、价值、可靠性）。[25]
- **难度/风险：**中等，引用潜力高。资源：仿真为主，π0.5 微调。

### B2. 面向物体的持久世界状态记忆，打通高层与低层

- **研究问题：**能否维护一组可被语言查询的物体记忆（身份、位置、状态、最后交互的动作-效果），同时供 VLM 规划器（3DLLM-Mem 式）和 VLA 动作专家（MEM/Zeva 式）读取？
- **为何仍开放：**高层的 3D 记忆不输出控制，低层记忆又没有物体结构（见第三节"断层"）。KARMA 有场景图但只做高层；Zeva 的动作-效果信号没有绑定到物体上。
- **方法草图：**用开放词汇检测、跟踪和深度维护物体槽位。每个槽位存语义嵌入、3D 位姿、状态文本，以及 CTE 风格的交互历史嵌入。高层通过文本或指针读取，低层通过 cross-attention 读取指定槽位的 token。训练信号包括：槽位重识别（自监督）、状态变化预测（动作-效果）、下游动作损失。
- **基准：**BEHAVIOR / RoboCasa365（移动操作、多房间）、RoboMME 空间/物体子集、3DMem-Bench。
- **难度/风险：**高。系统集成复杂，跟踪误差会传播。建议先在仿真中用真值物体身份做上界实验。

### B3. 用自监督取代 LLM 标签的记忆学习

- **研究问题：**MEM 的长期记忆依赖 LLM 生成的摘要标签。能否改用"预测未来、重建过去、预测动作效果"来学出同样有用的压缩记忆？
- **证据：**AEM 的掩码动作-效果预训练、PTP 的过去 token 预测、Cambrian-S 的惊奇度、WAM-TTT 的视频预测更新快速权重、Fast-WAM 关于"视频预测的价值主要在训练期塑造表示"的发现，都支持这一路线。[46][76][77]
- **方法草图：**定义一个记忆瓶颈（K 个 token），优化目标为：重建 Δt 前的关键状态，加上预测未来 H 步的潜变量，加上预测动作效果；用惊奇度控制写入。之后再接入 π0.5 动作专家做微调。
- **难度/风险：**中等。是否在下游有效，需要严格对照 MEM 式的语言标签方案。

### B4. 跨 episode 的终身上下文：上下文、快速权重、慢权重三级巩固

- **研究问题：**经验什么时候该留在上下文里（Zeva/MEM），什么时候该写进快速权重（RoboTTT/WAM-TTT），什么时候该进入慢权重（π*0.6 RECAP 的离线 RL）？能否像"睡眠巩固"那样，周期性地把高价值的上下文记忆蒸馏进 LoRA？
- **为何仍开放：**三条路线各自成立，但没有工作研究它们之间的迁移与遗忘。MEM 把"持续数周到数年的部署期持续学习"列为未来工作。[1]
- **方法草图：**部署期把 Zeva 式的 PIM 当作情景缓冲；周期性地选出高优势条目，用 LoRA 蒸馏进 π0.5，配合回放以防遗忘；在 LIBERO 的终身学习协议上评测前向/后向迁移。
- **难度/风险：**高，但正中 MEM 自述的未来工作，且可以完全用开源模型完成。

### B5. 多智能体或人机共享上下文

- **研究问题：**多台机器人或人与机器人之间如何共享、合并、校验记忆（谁看到了什么、何时看到）？
- **证据：**一篇 2026 年的观点论文（Embodied Collective Intelligence，arXiv 2606.27929）指出，个体 agent 产生的记忆、任务进度和经验"大多仍是私有的"。[78]
- **难度：**高，属于偏探索性的方向。建议排在后面。

### B6. 分离"表示失败 vs 检索失败 vs 使用失败"的诊断基准 ★推荐作为第一项产出

- **研究问题：**一个记忆系统失败时，原因是信息没写进去（表示），是写了但没取出来（检索），还是取出来了但策略没用（使用）？
- **方法草图：**对每个任务提供三种 oracle 干预：①oracle 写入（把真值信息放进记忆）；②oracle 检索（直接给出正确的记忆条目）；③oracle 使用（用探针解码记忆内容）。成功率的差值就是三类失败各自的占比。在 RoboMME 和 MIKASA-Robo-VLA 上实现，覆盖 RoboMME 已开源的 14 个 π0.5 变体。加入抗捷径设计，例如重复房间、视觉相似干扰物，以吸取 Cambrian-S 的教训。
- **难度/风险：**低，社区价值高，并且能为后续所有方法论文提供分析工具。

## 六、可用资源与实验建议

**开源模型与代码**

- openpi（π0 / π0.5）：RoboMME 的 14 个记忆变体、MemER 和 Zeva 的复现代码都基于 π0.5，是**首选底座**。
- MemoryVLA 代码（已集成进 Dexbotic 工具箱）。[79]
- Zeva 官方代码（air-embodied-brain/Zeva）。另有一个第三方的 RoboTwin + π0.5 实现，使用 Mamba 版 CTE，非官方，使用前请评估。Zeva-Ego 已在 Hugging Face 发布动作编码器等检查点。[80][81]
- MemoryWAM 代码；DiM-WAM 项目页；3DLLM-Mem 项目页（基于 LLaVA-3D）。
- MIKASA-Robo 可以直接 `pip install mikasa-robo-suite`（MIT 许可）。[75]
- Cosmos 3 可作为 WAM 底座（Zeva 即基于 Cosmos 系列）。

**基准选择建议**

- 低层操作：RoboMME（分类细，有 π0.5 基线族）、RMBench（有 M(1)/M(n) 分级，是 WAM 社区的常用基准）、MIKASA-Robo-VLA（90 个任务，可控提示间隔，含反应式对照组）、[71]RoboMME-Interference（跨会话）。
- 长时 System-2：RoboCerebra；LIBERO-Long / LIBERO-Plus。
- 高层空间：3DMem-Bench、HM3D/Habitat、MT-HM3D；OpenEQA 和 VSI-Bench 需要先核实版本与许可。
- 移动操作与家居：RoboCasa365、BEHAVIOR。

**实验设计硬规则**（吸取已有教训）

1. 必须包含"无记忆"和"oracle 记忆"两条基线，把记忆的上界与净贡献分开。
2. 必须报告策略自身 rollout 下（分布外历史）的表现，而不只报告示范回放；BPP 和 MemER 都表明两者差距巨大。
3. 必须做反事实交换记忆的测试，以及打乱帧序的测试。
4. 必须报告 chunk 长度与记忆增益的交互。
5. 真机实验至少做 20 次以上试验，并给出置信区间：DiM-WAM 每任务 10 次的结果只是点估计，反事实审计也显示动作采样种子的方差远大于交换记忆带来的影响。[25][43]

## 七、优先级建议

|优先级|方向|理由|周期估计|
|---|---|---|---|
|**P0**|B6 诊断基准 + B1 反事实忠实度|成本最低，问题最新（2026 年 9 月才有审计工作），能为后续所有工作提供工具，引用潜力高|3–4 个月|
|**P0**|A5 3DLLM-Mem 过期处理与可扩展检索|仿真、LLaVA-3D 微调、空白明确，适合快速出第一篇|2–3 个月|
|**P1**|A2 + A3：跨 episode 的 Zeva PIM 加学习型检索|直接回应 RoboMME-Interference 的"检索可恢复"发现；代码开源|3–5 个月|
|**P1**|A1 Grounded MEM 混合记忆|在 openpi 上可行，同时回应 MEM 和 MaP-WAM 指出的"语言丢细节"问题|4–6 个月|
|**P2**|B3 自监督记忆、B2 物体中心持久记忆|原创性强，但工程量大；建议先用真值物体身份做上界|6–12 个月|
|**P3**|B4 三级巩固的终身学习、B5 多智能体|长期愿景，宜在 P0/P1 产出工具和底座后再推进|12 个月以上|

**一句话策略：**先用诊断与反事实工具"证明现有记忆没被真正使用"，再用"结构化物体槽位 + 学习型检索 + 带遗忘的写策略"去修复它，最后把修复后的记忆扩展到跨 episode 和终身设定。这样每一步的产出都能自成一篇论文，并且前后衔接。

## 注意事项

- 本报告引用的 2026 年论文大多是 arXiv 预印本，未经同行评审；部分数字前后不一致（DiM-WAM 真机全任务成功率 80.0% 还是 90.0%、RMBench 基线 28.4% 还是 34.8%；RoboTTT 的 62% 还是 63%），引用时请注明口径。
- GEN-1.5 与 Skild S1 的数据来自公司博客和媒体，没有开放模型，无法复现，宜作为动机而非基线。
- 以下内容本轮未逐篇核实，使用前请自查：ConceptGraphs、HOV-SG、3D-Mem、Embodied-RAG、OpenEQA、TraceVLA、VSI-Bench、Spatial-MLLM、VLM-3R、"Present but Not Remembered"。CycleManip 和 π*0.6 的部分数字来自二手摘要。
- Zeva 的局限（评测规模小、"演化里程碑"而非尝试次数）主要来自用户提供的摘要；本轮核实了它的机制与 PIM 的"同一 episode 内"范围，但没有逐项核对评测细节。
