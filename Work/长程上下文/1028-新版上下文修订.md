## 一、修订（gpt 改共享代码，gpt3 原样合入）

**系统提示**
1. Input 段说明可能附一张历史图，例如："An optional HISTORICAL image from a past viewpoint may follow the current and before images."
2. Input 段说明记录字段的时间：记录里的 visibility、location_hint、bbox_normalized、observer_relation，以及文字里的 "current view"，说的都是 last_seen 那次观测的证据图，不是当前观测。
3. Task and completion 段说明判定时机：G1/G2 在每次新观测之后判；新阶段刚开始时还没有判，此时 observe 一次，当前画面就会被判。
4. 输出说明里的例子按 reason 的三步写全：先说 G1/G2，再说往哪看、为什么，最后点出动作。

**输入**
5. "多少次决策之前"按实际执行过的动作计数，脚本前缀也算在内，和 recent_actions 一致。
6. 程序视点索引里去掉当前视点。
7. 转向文字先四舍五入到 0.1°，再判断是否为零；为零时写 start direction 或不写转向。recent_actions 里的环视不写 turned，只留拍了几张、有没有回到起始朝向。
8. 历史图按这个顺序选，都不能是当前图或动作前那张：
   - 先用 Object 记录里当前目标最近一次目击的证据图。这里只用原始图片，不合并库的内容；
   - 没有的话，用重排后排在最前的程序视点；
   - 再没有，才取最近的视点。

   每次都记下历史图是按哪一条选出来的。

**输出和工具**
9. 解析参数之前，先去掉值为 null 的键。
10. BEHAVIOR 工具表里 move_to_point 的 distance_m 改为："optional travel distance cap; omit it to let the program use depth"。THOR 的写法不用改。

**Spatial 重排**
11. 提示第二句改为："Helpful items include places likely to contain the target and viewpoints that help reach them."

**测试**：只为第 5、6、7、8、9 条加针对性的测试。改完重新生成两个平台各 3 个样例的输入，可以调用重排，不调用规划器；旧版的提示和请求必须逐字节不变。
